# ADR-0008 · 内容 frontmatter schema 以现状为准（id/status/sources 必填）

- 状态：**Accepted（2026-10-22）**
- 日期：2026-10-22
- 关联：[ADR-0002](ADR-0002.md)（路径即 id）、[ADR-0007](ADR-0007.md)（章节 id 规则）、`packages/tooling/AGENTS.md`、`packages/tooling/src/validate.py`

## 上下文（Context）

仓库里存在一条**自相矛盾**的规则，会让新写的内容必被门禁打回：

- 规范侧：`packages/tooling/AGENTS.md:16`「frontmatter 不再手写 `id`」、`:30`「不写 id；status / sources 本期不要求、不回填」；`ARCHITECTURE.md:119`「`status / sources / review` 字段**可选**」；`AGENTS.md:14` 与 `CONTRIBUTING.md:57`「**不回填** 140 章 id/status/sources」。
- 代码与内容侧：`packages/tooling/src/validate.py:43-47` 把 `id/title/part/order/tags/difficulty/status` 与 `sources` 全部作为**硬错误**；实际 **140/140 章**都写了 `id/status/sources`（从首个内容提交 `7861a40` 起即如此）。

后果：按文档写新章 → `validate.py` 报 4 个硬错误；按校验器写 → 违反三份规范。`templates/site-template` 就是这个矛盾的第一个受害者（脚手架自带示例章过不了自己的校验器）。

需要澄清的是「不回填」的原意：ADR-0002 否决的是**为了重构而批量改写 140 章正文与 frontmatter**，不是禁止字段存在。

## 决策（Decision）

### 1. 以现状为准：`id/status/sources` 是必填字段

新章 frontmatter 必须包含：

```yaml
title: 章节标题              # 必填
part: 3                     # 必填 1-N，对应 content.config 的 PART_REGISTRY
chapter: 分组名              # 可空
order: 45                   # 必填，篇内排序，间隔取 5
tags: [运放, 反相放大]        # 必填，至少 1 个
difficulty: 2               # 必填 1入门/2进阶/3深入
status: published           # 必填（draft 不进离线册的 --published 构建）
sources:                    # 必填，至少 1 条
  - 来源名称或 URL
id: inverting-amplifier     # 必填，必须等于文件名（不含 .md），且全书唯一
```

- `id` 仍**不改变**「路径即 id」的运行时语义：manifest / 路由 / 学习数据用的是相对路径；frontmatter 的 `id` 只是写作期的一层一致性校验。
- `validate.py` 保持现有强度，**不放松**。

### 2. 「不回填」的准确含义

- **禁止**：为了重构而批量改写已有章节的正文/frontmatter（ADR-0002 的原意）。
- **允许且要求**：新增章节按上面 schema 写全字段。
- 已存在的 140 章不动；它们本来就有这些字段，因此无需回填。

### 3. 清理「冗余 id」列入 Backlog，不在本期做

`id` 与路径重复，改名时会多一处要同步。彻底解决要删掉 140 章的 `id` 并同步改校验器与 manifest，属数据格式变更，按 §ADR 规则应单独立项。**本期不做**。

## 验收（Verification）

- `python packages/tooling/src/validate.py --src templates/site-template/docs` 退出 0、硬错误 0（此前为 4）。
- `python packages/tooling/src/validate.py` 对硬件 140 章仍退出 0、硬错误 0，且不再有 `index.md` 假孤儿告警（与 `freeze_manifest.py:137` 的 skip 清单对齐）。
- 三份规范（`AGENTS.md`、`CONTRIBUTING.md`、`packages/tooling/AGENTS.md`）与 `ARCHITECTURE.md` 的表述与本 ADR 一致。

## 影响（Consequences）

- 新章写作成本 +4 行 frontmatter，但换来校验器与规范口径一致。
- 不触碰任何已有正文，内容指纹不变。
- 后续若要引入真正的稳定 id（与路径解耦），按 Backlog B2 另行 ADR。
