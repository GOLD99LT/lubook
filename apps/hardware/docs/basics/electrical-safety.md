# 安全用电与触电防护 Electrical Safety & Shock Protection

前面讲的都是"怎么让电路工作"，这一章讲"怎么不让电伤人"。市电 220V 足以致命——流过心脏的电流超过几十毫安就可能室颤。这是全书唯一一章"错了会出人命"的内容，务必认真。

## 1. 设计动机

::: motivation 为什么安全是第一优先级
设备可以烧、板子可以重做，人不能出事。触电、起火、电容放电、热表面烫伤——硬件工程师每天都在和这些风险打交道。保险丝、漏电保护器、接地、绝缘、放电电阻，这些不是"锦上添花"，是保命的底线。
:::

## 3. 触电是怎么回事（只给结论）

::: analogy 电流像穿过心脏的"小偷"
触电的危险不在于电压多高，而在于**流过心脏的电流多大、持续多久**。干燥皮肤电阻约 100kΩ，潮湿时降到 1kΩ 以下——同样 220V，潮湿时电流大 100 倍。
:::

人体对 50/60Hz 交流电流的大致反应（工程经验值）：

| 流过人体电流 | 大致感受/后果 |
|---|---|
| < 1 mA | 几乎无感 |
| 1~5 mA | 麻，能自主挣脱 |
| 10~20 mA | 肌肉痉挛，可能"被吸住"甩不开 |
| 50 mA 以上 | 呼吸困难、心室颤动风险 |
| 100 mA 以上、持续数秒 | 可致命 |

关键：**电流要形成回路才危险**。一手摸火线、脚踩地（或另一手摸零线/地线），电流穿过心脏，最危险。

## 4. 防护手段（结论）

- **保险丝/断路器**：电流过大时切断，防过流起火。
- **漏电保护器 RCD/GFCI**：检测 L 和 N 电流之差（漏到人体/大地的电流），约 30mA、0.1s 内跳闸——这是防触电最有效的一道。
- **保护接地 PE**：设备金属外壳接大地，绝缘失效时外壳电位≈0，人摸上去不触电；同时漏电流触发保护。
- **隔离变压器**：把设备与大地隔离，人单线接触不形成回路。
- **低电压安全特低电压 SELV**：如 12V/24V，干燥环境下即使触电也不致命。

::: advanced 进阶：为什么 50/60Hz 特别危险
工频交流与心脏搏动频率接近，容易诱发心室颤动；高频（如射频）电流倾向于从皮肤表面流过（趋肤效应），反而较少穿过心脏。所以同样毫安级电流，工频最危险。静电放电虽达上万伏，但能量极小、时间极短，通常只伤人不致命。
:::

## 5. 带数字的算例

::: example 算一下触电电流
1. **场景**：手湿（皮肤电阻 1kΩ），身体踩地电阻忽略，碰 220V 火线。
2. **电流**：$I=V/R=220/1000=$ **220 mA**——远超过致命阈值，非常危险。
3. **干燥皮肤**：电阻 100kΩ 时 $I=220/100k\approx2.2$ mA——只是麻。
4. **结论**：潮湿环境触电危险大得多；接地良好 + 漏电保护器（30mA 跳闸）能在到达致命电流前切断电源。
:::

## 6. 常见坑

::: pitfall 常见坑
- **断电后直接碰大电容**：现象——设备断电后仍被电一下。原因——大电解电容储存的电荷没放掉。解决——维修前用绝缘螺丝刀并泄放电阻给电容放电，这是硬规矩。
- **以为"关了开关"就没电**：现象——只断了零线，火线仍连设备。原因——开关接错线/单极开关断的是零线。解决——检修前用电笔验电，确认 L、N 都断，最好拔插头。
- **设备外壳不接地**：现象——摸麻手，但不跳闸。原因——绝缘轻微损坏让外壳带 220V，但漏电流小不够触发保护。解决——金属外壳必须接 PE，配漏电保护器。
:::

## 7. 自测题

<details><summary>同样碰 220V，为什么湿手比干手危险得多？</summary>

湿手皮肤电阻从约 100kΩ 降到约 1kΩ，触电电流从约 2mA（发麻）升到约 220mA（致命）。水把皮肤角质层浸湿、电阻骤降，电流暴涨。
</details>

<details><summary>漏电保护器（RCD）和普通保险丝有什么区别？</summary>

保险丝只在**电流过大**（短路）时熔断；RCD 检测 L/N 电流之差，在**漏电（哪怕 30mA 流经人体）**时 0.1s 内跳闸。保险丝防不了人触电——人体电阻大、电流远达不到熔断值。
</details>

<details><summary>设备金属外壳为什么要接 PE 地线？</summary>

绝缘一旦损坏，外壳会带上 220V。接 PE 后外壳被钳在地电位，人摸上去几乎无电流；同时漏电流经 PE 入地，触发漏电保护器/熔断保险丝切断电源。
</details>
