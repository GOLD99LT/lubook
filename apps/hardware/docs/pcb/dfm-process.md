# DFM 与焊接工艺 Design for Manufacturing

板子画得再好，如果做不出来、焊不上、良率低，就是失败设计。**DFM（Design for Manufacturing，可制造性设计）**就是让板子"既好做又好焊"。这一章讲板厂工艺边界和焊接工艺。

## 1. 设计动机

::: motivation 为什么要懂制造
新手常犯：线画到 3 mil、焊盘随便画、封装 0201，板子打回来不是做不出就是焊不上、良率低。DFM 的核心是——设计前先看板厂工艺能力表，在它能稳定做到的范围内设计，而不是想当然。
:::

## 2. 图示：回流焊温度曲线

![无铅回流焊四阶段：预热→恒温活化→回流(峰值~245℃)→冷却](../assets/schematics/dfm-process.svg)

## 3. 机理与定量：回流焊曲线

无铅焊锡（SAC305，锡银铜）关键参数：

- **液相线（Liquidus）**：217℃，焊锡熔化温度。
- **峰值温度**：240~250℃（比液相线高 ~25℃）。
- **TAL（Time Above Liquidus）**：液相线以上停留 30~90 秒。
- **升温斜率**：≤ 3℃/s（防热冲击、防立碑）。

板子和所有元件都要扛过这个热历程——塑料连接器、晶振都有耐温上限。

## 4. 设计准则

1. **线宽/间距 ≥ 板厂工艺下限**（常规 5mil/0.127mm）。
2. **焊环（Annular Ring）≥ 0.15mm**，防孔偏破盘。
3. **丝印不上焊盘**，否则影响上锡。
4. **元件布局考虑可焊性**：大元件别挡小元件焊盘。
5. **发热元件分布均匀**，别挤一堆局部过热。

## 5. 完整设计示例

::: example 一块新手板的 DFM 检查
1. **线宽**：信号 0.2mm、电源 0.5mm，都在常规工艺内 ✓。
2. **过孔**：0.3/0.6mm，常规可做 ✓。
3. **间距**：0.2mm，>5mil ✓。
4. **封装**：选 0805 电阻电容（好焊），没用 0201 ✓。
5. **丝印**：位号都避开了焊盘 ✓。
6. **布局**：极性元件方向一致，方便贴片和检查 ✓。
:::

## 6. 检查与仿真

- **DFM 检查工具**：板厂在线 DFM（如嘉立创 DFM 检查），上传 Gerber 自动查错。
- **首件核对（FAI）**：第一批板子核对位号、极性、焊接。
- **IPC-A-610**：焊接质量验收标准（焊点外观）。

## 扩展与变种电路

### 扩展1：板厂工艺能力边界

设计不能超出板厂能稳定做的范围。

![PCB 常规工艺下限：线宽5mil、过孔0.3/0.6、焊环0.15、阻焊桥0.1mm](../assets/schematics/dfm-rules.svg)

::: example 机理与定量
- **最小线宽/间距**：常规 0.127mm（5mil），新手用 0.2mm 更稳。
- **最小过孔**：钻 0.3mm / 盘 0.6mm；HDI 微孔另算钱。
- **焊环**：孔位有公差，焊环太小会偏破盘。
- **阻焊桥**：相邻焊盘间阻焊要够宽，防桥连。
- 打样用常规工艺最省钱；高密度才加钱做 HDI。
:::

准则对比：

| 工艺 | 线宽 | 成本 |
|---|---|---|
| 常规 | 5mil | 低 |
| HDI | 3mil 以下 | 高 |

::: pitfall 画了板厂做不出的线宽
- **现象**：下单被退回或加价做特殊工艺。
- **原因**：设计没看板厂能力表。
- **解决**：设计前看板厂工艺表，常规板用 5mil 规则。
:::

### 扩展2：钢网与锡膏印刷

SMT 贴片第一步是印锡膏，靠钢网。

![钢网开窗对应焊盘，锡膏漏印到 PCB 焊盘上](../assets/schematics/dfm-stencil.svg)

::: example 机理与定量
- **钢网厚度**：0.1~0.15mm 不锈钢片，开窗对应焊盘。
- **面积比（Area Ratio）**：开口面积/侧壁面积 >0.66，锡膏才能顺利脱模（不堵孔）。
- 细间距元件开口略小于焊盘，减少锡量防桥连。
- 封装选得太小（0201），钢网印刷良率骤降——设计阶段就要考虑。
:::

准则对比：

| 封装 | 印刷良率 |
|---|---|
| 0805 | 高 |
| 0402 | 中 |
| 0201 | 低（需精细钢网） |

::: pitfall 大焊盘锡量过多桥连
- **现象**：QFP 脚间锡桥连短路。
- **原因**：钢网开口太大、锡量过多。
- **解决**：细间距开口减小/内凹，或用阶梯钢网。
:::

## 7. 常见坑与故障现象

::: pitfall 常见坑
- **丝印印在焊盘上**：阻焊/丝印挡了上锡，虚焊。
- **极性元件方向乱**：贴片时贴反，极性电容/二极管烧。方向统一。
- **焊盘尺寸不对**：元件焊不上或立碑（见[封装库](schematic-library.md)）。
- **热布局与热历程冲突**：大铜箔散热导致局部温度跟不上曲线，冷焊。
:::

## 8. 自测题

<details><summary>无铅回流焊的峰值温度和液相线大约是多少？</summary>

液相线（SAC305）约 **217℃**，峰值温度 **240~250℃**，液相线以上停留（TAL）30~90 秒。板子和所有元件都要扛过这个热历程。

</details>

<details><summary>新手打样，线宽和间距建议用多少？为什么不画更细？</summary>

建议 **0.2mm（约 8mil）**，比常规下限 5mil 更宽裕。画太细不仅加价做 HDI，良率还低。打样阶段用常规工艺，省钱又稳，等真的高密度需求再上细线路。

</details>

<details><summary>钢网的"面积比"为什么要 >0.66？</summary>

面积比 = 开口面积/侧壁面积。>0.66 锡膏才能从开窗顺利脱模到焊盘上；太小锡膏堵在钢网里，印刷缺失、虚焊。这是 SMT 钢网设计的经验判据。

</details>
