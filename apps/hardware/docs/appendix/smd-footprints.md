# 附录 C · SMD 封装尺寸图

常见贴片封装的外形与典型尺寸。表里的**本体尺寸**取自厂商封装图（datasheet 的 Package Outline），**焊盘尺寸**取自 IPC-7351B 标称密度（Nominal）的库实现；两者都不是唯一答案——不同厂商同型号封装可能有 ±0.1 mm 级差异，生产前务必以具体厂商图纸与 EDA 库为准。

## C.1 片式无源元件（电阻/电容）

0402/0603/0805/1206 都是两端片式结构，仅尺寸不同。

![片式电阻/电容顶视图结构](../assets/schematics/smd-chip-passive.svg)

### 本体尺寸

| 英制代码 | 公制代码 | 本体长 L (mm) | 本体宽 W (mm) | 典型功率/电压 | 常用场景 |
|---|---|---|---|---|---|
| 0402 | 1005 | 1.00 | 0.50 | 1/16 W, 50 V | 高密度手机/板卡 |
| 0603 | 1608 | 1.60 | 0.80 | 1/10 W, 50 V | 最通用、好焊接 |
| 0805 | 2012 | 2.00 | 1.25 | 1/8 W, 150 V | 电源/功率余量 |
| 1206 | 3216 | 3.20 | 1.60 | 1/4 W, 200 V | 高功率/高压 |

> 英制代码 = 长×宽（千分之一英寸），如 0805 ≈ 0.08×0.05 inch。公制代码 = 长×宽（0.1 mm 为单位），0805 记作 2012（2.0×1.2），但实际本体宽常见 1.25 mm——代码是“标称栅格”，不是精确尺寸。0402 = 40×20 mil ≈ 1.0×0.5 mm。

### 焊盘（IPC-7351B 标称密度）

| 封装 | 单焊盘 X×Y (mm) | 焊盘中心距 (mm) | 两焊盘内侧间隙 (mm) | 备注 |
|---|---|---|---|---|
| 0402 | 0.54 × 0.64 | 1.02 | 0.48 | 手焊难度大，建议钢网 |
| 0603 | 0.80 × 0.95 | 1.65 | 0.85 | 手焊友好，最常用 |
| 0805 | 1.025 × 1.40 | 1.825 | 0.80 | 功率余量大 |
| 1206 | 1.125 × 1.75 | 2.925 | 1.80 | 注意热应力与立碑 |

> 焊盘尺寸的口径：X 是沿元件长度方向的尺寸，Y 是沿宽度方向。IPC-7351B 有 Least/Nominal/Most 三档密度，上表为 Nominal（通用）；高密度板可用 Least，返修/手工焊可用 Most（焊盘外扩 0.1–0.2 mm）。焊盘间距不要照抄本体长度，端头电极占掉一部分，真正决定间隙的是元件端头尺寸。

## C.2 SOT-23（三极管/MOSFET/基准）

![SOT-23-3 顶视图](../assets/schematics/smd-sot23.svg)

| 参数 | 典型值 |
|---|---|
| 本体尺寸 | 2.9 × 1.3 mm（高约 1.0 mm） |
| 引脚数 | 3（SOT-23-3）；另有 5/6 脚变体（SOT-23-5/6） |
| 相邻引脚节距 | 0.95 mm |
| 同侧两脚中心距 | 1.90 mm |
| 焊盘（标称） | 0.90 × 0.80 mm，两脚在 x = −1.0 mm（y = ±0.95 mm），单脚在 x = +1.0 mm |
| 典型器件 | S8050、AO3400、TL431、LM4040 |

> SOT-23 的“脚距”有两个口径：同侧两脚中心距 1.90 mm，相邻引脚节距 0.95 mm。画封装时按 EDA 库的焊盘坐标，不要按本体宽度推算。SOT-23-5/6 的节距仍是 0.95 mm，但引脚数增加、焊盘更窄，买料前先确认后缀。

## C.3 SOT-223（小功率稳压/功率器件）

| 参数 | 典型值 |
|---|---|
| 本体尺寸 | 6.5 × 3.5 mm（高约 1.6–1.8 mm） |
| 引脚数 | 4（3 个引脚 + 1 个大焊片 Tab，Tab 通常接散热/地或输出） |
| 引脚节距 | 2.30 mm |
| 引脚焊盘（标称） | 2.0 × 1.5 mm，三脚在 x = −3.15 mm（y = −2.3 / 0 / +2.3 mm） |
| Tab 焊盘（标称） | 2.0 × 3.8 mm，位于 x = +3.15 mm |
| 典型器件 | AMS1117、LM1117、NCP1117 等线性稳压器 |

> SOT-223 的 Tab 是大面积铜，散热靠它：PCB 上要铺铜并多打过孔到地/电源层，否则 1 A 输出时结温会迅速上去。焊盘尺寸随密度档变化，散热焊盘可以比表中更大，但不要大到让锡膏把元件“浮”起来。

## C.4 SOIC（小外形集成电路）

![SOIC-8 顶视图](../assets/schematics/smd-soic.svg)

| 参数 | SOIC-8 典型值 |
|---|---|
| 本体宽 | 3.9 mm（窄体）/ 7.5 mm（宽体） |
| 本体长 | ≈4.9 mm |
| 引脚间距（pitch） | 1.27 mm |
| 引脚数 | 8（也有 14/16/20/24） |
| 典型器件 | LM358、NE5532、W25Q64、MAX485 |

> SOIC 的 1.27 mm 正好是 50 mil，是老一代通孔/贴片混合板最友好的节距；窄体 3.9 mm 与宽体 7.5 mm 的焊盘不能混用。

## C.5 TSSOP（薄型细脚距）

![TSSOP-16 顶视图](../assets/schematics/smd-tssop.svg)

| 参数 | TSSOP-16 典型值 |
|---|---|
| 本体宽 | ≈4.4 mm |
| 本体长 | ≈5.0 mm |
| 引脚间距 | 0.65 mm（高引脚数型号有 0.5 mm） |
| 引脚数 | 16（8×2；常见 20/24/28/48） |
| 典型器件 | 74HC595、CH340、EEPROM、逻辑/接口芯片 |
| 特点 | 比 SOIC 更薄更密，手持焊难度高 |

> 0.65 mm 节距已经接近手工焊接的极限：焊盘间容易桥连，建议钢网 + 回流焊；返修用热风枪而不是烙铁拖焊。

## C.6 QFP（方形扁平封装）

![QFP 顶视示意（焊盘数量未按比例）](../assets/schematics/smd-qfp.svg)

| 参数 | LQFP-32 典型值 |
|---|---|
| 本体尺寸 | 7 × 7 mm（或 9 × 9） |
| 引脚间距 | 0.8 mm（LQFP） |
| 引脚数 | 32（四面各 8） |
| 焊盘（标称） | 长 1.5–1.8 mm、宽 0.5–0.55 mm（随密度档变化） |
| 典型器件 | STM32G030K8T6（LQFP-32） |

> LQFP 与 TQFP 的差别主要在厚度（LQFP 约 1.4 mm，TQFP 约 1.0 mm），焊盘可以共用但钢网厚度不同。0.5 mm 节距的 LQFP 需要更薄的钢网（0.10–0.12 mm）。

## C.7 QFN / DFN（无引脚方形扁平）

![QFN 顶视示意（焊盘数量未按比例）](../assets/schematics/smd-qfn.svg)

| 参数 | QFN-16 典型值（3×3 mm） |
|---|---|
| 本体尺寸 | 3 × 3 mm（或 4×4、5×5） |
| 引脚间距 | 0.5 mm（或 0.65/0.4） |
| 周边焊盘（标称） | 0.875 × 0.25 mm，中心在 ±1.4375 mm |
| 中央裸露焊盘（EP） | 1.45 × 1.45 mm（随型号变化） |
| 焊接要点 | 需钢网 + 回流焊，手焊难度大 |
| 典型器件 | ESP32-C3、电源 IC、射频前端 |

> QFN 的中央 EP 必须接地并开散热过孔（常见 3×3 到 5×5 阵列，孔径 0.2–0.3 mm）；EP 与周边焊盘之间要留阻焊坝，否则锡膏回流时容易短路。DFN 是 QFN 的两边引脚版本，规则相同。

## C.8 尺寸来源、公差与密度等级

| 项目 | 口径 |
|---|---|
| 本体尺寸 | 厂商 datasheet 的 Package Outline，通常给 min/nom/max；本表取 nom |
| 焊盘尺寸 | IPC-7351B 标称密度（Nominal），KiCad 官方库按此生成 |
| 密度等级 | Least（高密度）、Nominal（通用）、Most（返修/手工焊） |
|  courtyard | 在焊盘外再留 0.25 mm（片式）到 0.5 mm（IC）的禁布区 |
| 丝印 | 不得压在焊盘上；元件外框可略小于本体 |
| 公差 | 0402/0603 本体常见 ±0.05 mm，0805/1206 ±0.10 mm；以厂商图纸为准 |

> **不要用本表直接出 Gerber**。正确做法：在 EDA 里选厂商/标准库封装 → 对照 datasheet 的推荐焊盘图 → 检查 courtyard 与丝印 → 打样前做 1:1 打印比对。IPC-7351B 给的是“可制造”的起点，不是唯一正确值。

## C.9 选型与焊接建议

::: pitfall 封装与焊接工艺匹配
- **0402 及以下**：手焊极难，建议回流焊/钢网；面包板上无法直接插。
- **QFN/DFN**：中央裸露焊盘必须在 PCB 上对应开窗并接地，否则散热不良；手焊需热风枪。
- **TSSOP/QFP 细脚距**：0.65 mm 以下脚距建议用钢网印刷，飞线修复困难。
- **焊盘设计**：优先用 IPC-7351 计算 land pattern，KiCad 封装库已按标准提供，勿手动画尺寸。
- **Pin 1 方向**：所有封装均有 Pin 1 标记（圆点/缺口/斜角），贴装与焊接前务必核对方向，反贴会烧片。
- **受潮**：QFN/QFP 拆封后按 J-STD-020 的 MSL 等级烘烤，受潮回流会爆米花（delamination/popcorn）。
:::

> 本节图形为示意结构，非精确工程图；生产用 Gerber 请从 EDA 库或 datasheet 提取精确尺寸。

## C.10 速查自检

<details><summary>0603 的焊盘中心距为什么是 1.65 mm，而不是本体长 1.60 mm？</summary>

焊盘中心距由“本体长 + 两端电极外伸 − 焊盘内缩”决定，不是本体长。IPC-7351 标称值 1.65 mm 让焊料形成合适 fillet；直接用 1.60 mm 会导致焊盘偏小、立碑风险增加。

</details>

<details><summary>SOT-23 的同侧脚距和相邻节距分别是多少？</summary>

同侧两脚中心距 1.90 mm，相邻引脚节距 0.95 mm（SOT-23-5/6 也是 0.95 mm 节距）。

</details>

<details><summary>为什么 QFN 的中央焊盘必须接地？</summary>

它既是散热路径（热阻 $R_{\theta JC}$ 主要从这里走），也是某些芯片的电气地/衬底连接。不接地会同时导致过热和功能异常。

</details>

<details><summary>0805 的公制代码 2012 是不是 2.0×1.2 mm？</summary>

代码是 2.0×1.2 的标称栅格，实际本体宽常见 1.25 mm（如 2.0×1.25 mm）。以 datasheet 的本体尺寸为准，不要用代码反推焊盘。

</details>
