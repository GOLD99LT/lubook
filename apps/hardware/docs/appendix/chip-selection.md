# 附录 D · 常用芯片选型速查

按功能分类列出工程中最常见、最易采购的型号。参数为典型值，正式设计前务必核对最新 datasheet（数据手册）。厂商型号归各自所有。**选型不是“挑一个参数最大的”，而是先列出不可妥协的边界（电压、电流、温度、精度、封装、供货），再用最坏情况逐条验算。**

## D.0 五步选型法与降额

1. **写需求边界**：输入/输出范围、负载电流、环境温度、精度、封装、成本、生命周期。
2. **筛候选**：先按“电压/电流/温度”三条硬线筛，剩 3–5 个再看精度与外围。
3. **最坏情况验算**：用 datasheet 的 min/max（不是 typical），算功耗、结温、误差预算、时序。
4. **核对外围**：补偿网络、ESR 范围、最小负载、启动时序、保护（OVP/OCP/OTP）。
5. **确认供货**：封装/尾缀、MSL 等级、是否 NRND/EOL、替代料引脚是否兼容。

| 器件 | 参数 | 常用降额（工程内部规范，非标准强制） |
|---|---|---|
| 电阻 | 功率 | ≤ 额定功率的 50%–60% |
| 陶瓷电容 | 直流电压 | ≤ 额定电压的 50%–70%（留 DC Bias 余量） |
| 电解电容 | 电压/纹波电流 | 电压 ≤ 80%，纹波电流 ≤ 80% |
| MOSFET | $V_{DS}$ / $I_D$ / $T_j$ | 电压 ≤ 70%–80%，电流 ≤ 70%–80%，$T_j$ ≤ 80% $T_{j(max)}$ |
| 二极管 | 反向电压/正向电流 | 电压 ≤ 70%–80%，电流 ≤ 70% |
| LDO / DC-DC | 输出电流 / $T_j$ | 电流 ≤ 70%–80%，$T_j$ ≤ 80% $T_{j(max)}$ |
| 连接器 | 每针电流 | ≤ 50%–70% 额定 |
| 稳压管/TVS | 功率 | ≤ 50% 额定 |

> 降额的本质是给“参数分散 + 温升 + 老化”留余量。datasheet 的绝对最大值（Absolute Maximum）不是工作点，超过它哪怕一瞬间也可能永久损坏；工作点要落在 Recommended Operating Conditions 内，再按上表降额。

### 运放选型判据（可量化）

| 判据 | 公式/条件 | 说明 |
|---|---|---|
| 带宽 | $\text{GBP}\ge 100\cdot G\cdot f_{max}$（1% 增益误差） | $G$ 为闭环增益，$f_{max}$ 为最高工作频率；要 0.1% 误差则系数取 1000 |
| 压摆率 | $\text{SR}\ge 2\pi f_{max}V_{peak}$，再留 1.5–2 倍 | SR 单位 V/s，datasheet 常给 V/µs（除以 $10^{6}$）；方波看阶跃响应 |
| 输入偏置 | $I_B\cdot R_{source}\le 0.1\times$ 允许误差 | 高阻源选 CMOS/JFET 输入 |
| 失调 | $V_{OS}+V_{OS,drift}\Delta T\le$ 误差预算 | 直流精度看这个，不看 GBP |
| 噪声 | $e_n\le$ 允许输入噪声密度 | 与源电阻热噪声平方和合成 |
| 输出摆幅 | 在满载电流下仍满足后级输入范围 | 轨到轨也要看负载 |
| 稳定性 | 相位裕度 ≥ 45°（目标 60°） | 看噪声增益、负载电容、容性负载隔离 |

> 例：100 kHz、G=10、要求 1% 增益误差，则 GBP ≥ $100\times10\times10^5=100$ MHz；若只要求 10% 误差，系数取 10，GBP ≥ 10 MHz 即可。很多“1 MHz 运放做 10 倍放大”的电路，在 10 kHz 以上增益就开始塌，原因就在这里。

|---|---|---|---|
| LM339 | TI / onsemi | 四比较器，集电极开路输出，单电源 2~36 V | 最通用、最便宜，需外部上拉 |
| LM311 | TI / onsemi | 单比较器，响应约 200 ns，输出可配置（开集/开射） | 电压检测、过流保护，非高速场景 |

## D.3 电压基准 Voltage Reference

| 型号 | 厂商 | 关键参数 | 典型用途/备注 |
|---|---|---|---|
| LM4040 | TI / Microchip | 2.5 V/4.096 V/5 V，±0.1%（A 档），低功耗 | ADC 基准常用，并联型需限流电阻 |
| REF3030 | TI | 3.0 V 基准，±0.2%，SOT-23-3 | 3.3 V 系统 ADC 基准 |
| ADR4525 | ADI | 2.5 V 超高精度基准，低噪声 | 精密仪器、校准 |
| TL431 | TI / 多家 | 可调并联基准（2.5 V 起步），2.5~36 V | 可调稳压、电源反馈 |

- **判据**：初始精度 + 温漂 + 长期漂移 + 噪声，四项按最坏情况合成后要小于 ADC 的 1 LSB。
- **算例**：12 位、3.3 V ADC 的 1 LSB = $3.3/4096=0.806$ mV；3.0 V 基准 ±0.2% = ±6 mV ≈ 7.4 LSB。也就是说基准误差占掉约 7.4 个 LSB（12 位里损失约 2.9 位），精密测量要用 0.05% 级基准或软件校准。
- **注意**：并联基准（LM4040、TL431）要算限流电阻与负载电流范围；串联基准的 dropout 与输出电流要留余量。

### LDO 选型判据（可量化）

| 判据 | 条件 | 说明 |
|---|---|---|
| 压差 | $V_{in(min)}\ge V_{out}+V_{dropout(max)}+V_{ripple}$ | 压差随电流/温度变差，按 max 算 |
| 结温 | $T_j=T_a+(V_{in}-V_{out})I_{out}R_{\theta JA}\le0.8T_{j(max)}$ | 这是最容易翻车的一条 |
| 静态电流 | $I_q\ll I_{load}$（电池设备） | AMS1117 的 5 mA 对 µA 级负载是灾难 |
| 稳定性 | 输出电容 ESR 在 datasheet 允许窗口内 | 有些 LDO 要求钽电容/最小 ESR |
| PSRR | 在开关频率处 ≥ 需求 | PSRR 随频率下降，别只看 1 kHz |

> 算例：5 V→3.3 V、0.5 A、$R_{\theta JA}=60$ °C/W、$T_a=50$ °C，$P=1.7\times0.5=0.85$ W，$T_j=50+0.85\times60=101$ °C；若 $T_{j(max)}=125$ °C，0.8 倍降额上限是 100 °C，已经**超了 1 °C**。要么加大铜箔/过孔把 $R_{\theta JA}$ 降下来，要么把电流降到 0.45 A，要么换开关电源。

### Buck 选型判据（可量化）

| 判据 | 公式 | 说明 |
|---|---|---|
| 占空比 | $D\approx\dfrac{V_{out}}{V_{in}\eta}$ | $\eta$ 取 0.80–0.95，别用 1 |
| 电感 | $L=\dfrac{V_{out}(1-D)}{\Delta I_L f_{sw}}$ | $\Delta I_L$ 取 0.2–0.4 $I_{out}$ |
| 输出电容 | $\Delta V\approx\dfrac{\Delta I_L}{8f_{sw}C}+\Delta I_L\cdot ESR$ | ESR 项常占主导 |
| 输入电容 RMS | $I_{cin}\approx I_{out}\sqrt{D(1-D)}$ | 选 X7R，按纹波电流降额 |
| 结温 | $T_j=T_a+P_{loss}R_{\theta JA}\le0.8T_{j(max)}$ | 损耗含导通、开关、驱动、静态 |
| 最小负载 | 检查 DCM/脉冲跳跃是否可接受 | 轻载纹波/啸叫常见 |

> 算例：12 V→5 V、2 A、$f_{sw}=500$ kHz、$\eta=0.9$，$D=5/(12\times0.9)=0.463$；取 $\Delta I_L=0.6$ A，$L=5\times0.537/(0.6\times5\times10^5)=8.9$ µH，选 10 µH。输入电容 RMS：$2\sqrt{0.463\times0.537}=1.0$ A，至少选 2 颗 10 µF X7R 并联（按纹波电流与降额）。

### MOSFET 选型判据（可量化）

- **耐压**：$V_{DS}\ge1.5\sim2\times V_{in}$（含尖峰）；开关节点振铃用示波器实测，别只按直流算。
- **电流**：$I_D\ge2\times I_{load}$；注意 $I_D$ 的测试条件（$T_c=25$ °C）与实际 PCB 差很远。
- **导通损耗**：$P_{cond}=I_{rms}^2R_{DS(on)}$，$R_{DS(on)}$ 取**实际 $V_{GS}$ 与 $T_j$** 下的值（热了会变大）。
- **开关损耗**：$P_{sw}\approx\dfrac12V_{DS}I_D(t_r+t_f)f_{sw}$；频率越高越要选低 $Q_g$。
- **驱动**：$I_{gate}\approx Q_g f_{sw}$，$P_{gate}=Q_gV_{GS}f_{sw}$；驱动器峰值电流要够。
- **热**：$T_j=T_a+P_{total}R_{\theta JA}\le0.8T_{j(max)}$；SOT-23 的 $R_{\theta JA}$ 常 200–300 °C/W，别按 TO-220 的经验拍脑袋。

> 算例：$R_{DS(on)}=30$ mΩ、3 A、占空比 0.5，$P_{cond}=9\times0.03\times0.5=0.135$ W；SOT-23 的 $R_{\theta JA}=250$ °C/W，温升 34 °C，50 °C 环境时 $T_j=84$ °C，可接受；若 $R_{DS(on)}$ 因温升翻倍，则要重算。

| TP5000 | 南京拓微 | 2 A 开关充电 | 大电流充电 |

- **判据**：充电电流 ≤ 电池 1C（常规 0.5C）；$P=(V_{in}-V_{bat})I_{chg}$ 要按最大压差算结温；终止电压精度（4.2 V ±1%）；是否有 JEITA 温控、定时器、电池反接保护。
- **算例**：TP4056、5 V 输入、4.2 V/1 A，$P=0.8$ W；SOP-8 的 $R_{\theta JA}$ 约 100 °C/W，温升 80 °C，必须铺铜散热，否则芯片会热到限流。

::: pitfall 选型注意：别只看标称参数
- **电源电流余量**：LDO/DC-DC 标称 1 A 不等于能持续输出 1 A，需算散热与铜箔。
- **逻辑电平不匹配**：3.3 V MCU 直连 5 V 传感器可能读不到高电平或损坏 IO，加电平转换。
- **最小负载**：某些 DC-DC（尤其是不连续模式）轻载时效率暴跌或输出飘，加假负载。
- **替代型号封装/引脚**：即使同型号名，不同厂商或尾缀可能引脚不同，换料务必核对脚图。
- **型号后缀**：FM24V02 是 256 Kbit，24C02 是 2 Kbit；LM358 与 LM2904 耐压不同；MAX485 与 SP3485 供电不同。读型号要读到后缀。
:::

## D.12 速查自检

<details><summary>100 kHz、G=10、要求 1% 增益误差，运放 GBP 至少多少？</summary>

$\text{GBP}\ge100\times10\times10^5=100$ MHz。若只要求 10% 误差，系数取 10，10 MHz 就够。

</details>

<details><summary>5 V→3.3 V、0.5 A、RθJA=60 °C/W、Ta=50 °C，AMS1117 结温多少？</summary>

$P=1.7\times0.5=0.85$ W，$T_j=50+0.85\times60=101$ °C；对 125 °C 的 80% 降额线（100 °C）已经超出，需要加铜箔或降电流。

</details>

<details><summary>12 V→5 V、2 A、500 kHz、ΔIL=0.6 A，电感取多大？</summary>

$D=5/(12\times0.9)=0.463$，$L=5\times0.537/(0.6\times5\times10^5)=8.9$ µH，取 10 µH 标称值。

</details>

<details><summary>FM24V02 和 24C02 的容量分别是多少？</summary>

FM24V02 是 256 Kbit = 32 KB；24C02 是 2 Kbit = 256 B。两者差 128 倍，型号后缀不能按“02”猜。

</details>
