# 附录 H · 面包板实验清单

18 个递进实验，从认识电压到综合小系统。每个含目标、所需元件、接线步骤、预期现象与思考题。建议配万用表、面包板、5V 电源（或 USB）。

> 安全提示：实验电压限 5V/3.3V，不要接市电；上电前先用万用表通断档确认无短路。

## 实验 1：认识面包板与电压测量

| 项 | 内容 |
|---|---|
| 目标 | 熟悉面包板内部连接，学会万用表测电压 |
| 元件 | 面包板、USB 5V 线、万用表 |
| 步骤 | ① USB 5V 接面包板红轨；② 黑表笔接蓝轨，红表笔测红轨 |
| 预期 | 万用表读数约 5.0V；红轨内部所有孔连通 |
| 思考 | 面包板中间纵列（1-5）与横列（a-e）连通规律是什么？ |

## 实验 2：点亮 LED

| 项 | 内容 |
|---|---|
| 目标 | 理解限流电阻的必要性 |
| 元件 | LED、220Ω 电阻、5V |
| 步骤 | 5V → 220Ω → LED 阳极 → LED 阴极 → GND |
| 预期 | LED 微亮；若直接接 LED 不加电阻则很亮甚至烧毁 |
| 思考 | 若要更暗应加大还是减小电阻？电流约多少 mA？ |

## 实验 3：电阻分压

| 项 | 内容 |
|---|---|
| 目标 | 验证分压公式 $V_{out}=V_{in}\cdot R_2/(R_1+R_2)$ |
| 元件 | 10kΩ、10kΩ 电阻、5V、万用表 |
| 步骤 | 5V→R1(10k)→节点 Vout→R2(10k)→GND，测 Vout |
| 预期 | Vout ≈ 2.5V |
| 思考 | 把 R2 换成 1k，Vout 变为多少？接负载后为何偏低？ |

## 实验 4：上拉电阻与按键

| 项 | 内容 |
|---|---|
| 目标 | 理解上拉电阻与机械开关 |
| 元件 | 10kΩ 电阻、轻触按键、LED、5V |
| 步骤 | 节点经 10k 上拉到 5V，按键一端接 GND，节点接 LED→GND |
| 预期 | 常态 LED 亮（节点被上拉到高电平）；按下按键节点被拉低到 GND，LED 灭 |
| 思考 | 若无上拉电阻，按下松开后节点电平为何不确定？ |

## 实验 5：RC 充电时间常数

| 项 | 内容 |
|---|---|
| 目标 | 观察电容充电曲线，理解 $\tau=RC$ |
| 元件 | 100µF 电解电容、10kΩ 电阻、5V、万用表/示波器 |
| 步骤 | 5V→R→C→GND，上电后测电容两端电压随时间 |
| 预期 | 1 秒（$\tau=RC=10\text{k}\times100\mu=1\text{s}$）时充到约 3.2V（63%） |
| 思考 | 若电容换成 10µF，充电快多少倍？ |

## 实验 6：RC 低通滤波

| 项 | 内容 |
|---|---|
| 目标 | 观察 RC 低通对信号的衰减 |
| 元件 | 1kΩ、1µF、信号发生器/MCU PWM |
| 步骤 | PWM（1kHz）→R→输出节点→C→GND，示波器看输入输出 |
| 预期 | 方波变成平滑直流；频率越高输出越小 |
| 思考 | 截止频率 $f_c=1/(2\pi RC)$ 约多少 Hz？ |

## 实验 7：BJT 三极管开关

| 项 | 内容 |
|---|---|
| 目标 | 用小基极电流控制大集电极电流 |
| 元件 | S8050/2N3904 NPN、1kΩ、LED、220Ω、5V |
| 步骤 | MCU GPIO(或按键+上拉)→1k→基极；集电极→LED→220Ω→5V；发射极→GND |
| 预期 | 基极高电平时 LED 亮，低电平时灭；基极电流远小于 LED 电流 |
| 思考 | 基极电阻取多大？饱和条件 $I_B>I_C/\beta$ 怎么算？ |

## 实验 8：MOSFET 开关

| 项 | 内容 |
|---|---|
| 目标 | 对比 MOSFET 与 BJT，理解电压控制 |
| 元件 | AO3400/2N7000 N-MOS、LED、220Ω、5V |
| 步骤 | GPIO→栅极（串 1k）；漏极→LED→220Ω→5V；源极→GND |
| 预期 | GPIO 高电平 MOS 导通，LED 亮；栅极几乎不取电流 |
| 思考 | 为什么 MOS 栅极不需要持续电流？栅极电容有什么影响？ |

## 实验 9：LDO 稳压

| 项 | 内容 |
|---|---|
| 目标 | 用 AMS1117-3.3 把 5V 变 3.3V |
| 元件 | AMS1117-3.3、10µF 输入电容、10µF 输出电容、5V |
| 步骤 | 5V→IN，GND→GND，OUT 接负载，并联电容 |
| 预期 | OUT 稳定 3.3V；输入波动被抑制 |
| 思考 | 压差是多少？LDO 自身功耗 $P=(V_{in}-V_{out})\cdot I$ 多大？ |

## 实验 10：Buck 降压模块

| 项 | 内容 |
|---|---|
| 目标 | 认识开关电源高效率 |
| 元件 | LM2596/MP1584 模块、电位器、万用表 |
| 步骤 | 12V（或 9V）输入，调电位器使输出 5V，接不同负载 |
| 预期 | 输出稳定 5V，效率明显高于 LDO |
| 思考 | 为什么开关电源效率比线性高？纹波大在哪？ |

## 实验 11：反相比例放大器

| 项 | 内容 |
|---|---|
| 目标 | 用 LM358 搭反相放大器，验证 $G=-R_f/R_1$ |
| 元件 | LM358、10k、100k、双电源 ±5V（或单电源+偏置）、信号源 |
| 步骤 | Vin→10k→反相端；反相端→100k→输出；同相端接地 |
| 预期 | 输出幅度为输入 10 倍、相位相反 |
| 思考 | 单电源 5V 下输出负半周为什么被削？ |

## 实验 12：同相比例放大器

| 项 | 内容 |
|---|---|
| 目标 | 高输入阻抗缓冲/放大 |
| 元件 | LM358、10k、10k、信号源 |
| 步骤 | Vin→同相端；反相端经 R1 接地、经 Rf 接输出 |
| 预期 | $G=1+R_f/R_1=2$，输出与输入同相 |
| 思考 | 电压跟随器（Rf=0、R1 开路）输入阻抗为什么极高？ |

## 实验 13：比较器与迟滞

| 项 | 内容 |
|---|---|
| 目标 | 用 LM339 做阈值检测，加迟滞抗抖 |
| 元件 | LM339、电位器、10k、100k、LED |
| 步骤 | 同相端接电位器分压，反相端接输入信号，输出上拉 10k 到 LED |
| 预期 | 输入越过阈值时输出翻转；加正反馈电阻后上下阈值不同 |
| 思考 | 没有迟滞时输入在阈值附近抖动，LED 为何闪烁？ |

## 实验 14：按键去抖

| 项 | 内容 |
|---|---|
| 目标 | 观察机械按键抖动，用 RC 去抖 |
| 元件 | 按键、100nF、10k、MCU 或示波器 |
| 步骤 | 按键节点直接接示波器 vs 并联 100nF 到 GND |
| 预期 | 直接接：按下瞬间示波器看到十几 ms 的抖动；加电容后平滑 |
| 思考 | RC 时间常数取多少合适？太大有什么副作用？ |

## 实验 15：I²C 上拉与扫描

| 项 | 内容 |
|---|---|
| 目标 | 理解 I²C 开漏+上拉 |
| 元件 | MCU、24C02 EEPROM、两个 4.7kΩ 电阻 |
| 步骤 | SDA/SCL 各经 4.7k 上拉到 3.3V，连 MCU 与 EEPROM |
| 预期 | MCU 扫描到 0x50 地址的 EEPROM；无上拉则总线高电平不确定 |
| 思考 | 为什么 I²C 用开漏+上拉而不是推挽？ |

## 实验 16：整流与滤波

| 项 | 内容 |
|---|---|
| 目标 | 观察交流变直流的全过程 |
| 元件 | 1kΩ、二极管 1N4148×4、电解 100µF、信号发生器（1kHz 1Vpp） |
| 步骤 | 信号源→桥式整流→电容滤波→电阻负载，示波器逐级观察 |
| 预期 | 正弦→馒头波→平滑直流；加电容后纹波减小 |
| 思考 | 全波整流后频率变成多少？电容越大纹波越小吗？ |

## 实验 17：H 桥电机驱动

| 项 | 内容 |
|---|---|
| 目标 | 用 4 个 MOSFET/三极管控制电机正反转 |
| 元件 | L9110S（或分立 4×N-MOS）、小直流电机、MCU |
| 步骤 | IN1/IN2 接 GPIO：IN1=1/IN2=0 正转；反之反转；都 0 滑行 |
| 预期 | 电机按 GPIO 状态正反转；PWM 可调速 |
| 思考 | 什么是"直通"（shoot-through）？为什么必须避免？ |

## 实验 18：综合小系统——ADC 采样点灯

| 项 | 内容 |
|---|---|
| 目标 | 把前面所有实验串起来：分压→ADC→LED |
| 元件 | MCU、电位器、LED、限流电阻 |
| 步骤 | 电位器分压接 MCU ADC，程序读 ADC 值，超过阈值点亮 LED |
| 预期 | 旋转电位器，电压升高到阈值时 LED 亮 |
| 思考 | 若电位器线很长，ADC 读数跳动怎么办？（去耦/滤波/差分） |

---

> 建议按顺序做，每完成一个实验用示波器抓波形存档。面包板接触不良是最常见故障——导线插紧、IC 引脚确认插在同一纵列。
