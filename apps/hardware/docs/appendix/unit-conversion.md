# 附录 E · 单位换算与常用常数

工程中最常碰到的单位换算与物理常数，汇总成表随用随查。

## E.1 国际单位制词头（SI Prefixes）

| 词头 | 符号 | 因子 | 常见量 |
|---|---|---|---|
| pico | p | $10^{-12}$ | pF（皮法）、pA |
| nano | n | $10^{-9}$ | nF（纳法）、nV/√Hz、ns |
| micro | $\mu$ | $10^{-6}$ | µF、µA、µs、µV |
| milli | m | $10^{-3}$ | mV、mA、mW、mm |
| （无） | — | $10^{0}$ | V、A、W、Ω、Hz |
| kilo | k | $10^{3}$ | kΩ、kHz、kV、kW |
| mega | M | $10^{6}$ | MΩ、MHz、MW |
| giga | G | $10^{9}$ | GHz、GΩ |

> 注意：$1\mu F=1000\text{nF}=1000000\text{pF}$；$1\text{nF}=1000\text{pF}$。电容单位换算是最易错点。

## E.2 电压 / 电流 / 功率 / 能量换算

### 基本关系

| 量 | 公式 | 单位 |
|---|---|---|
| 欧姆定律 | $V=I\cdot R$ | V = A·Ω |
| 功率（直流） | $P=V\cdot I=I^2R=V^2/R$ | W |
| 能量 | $E=P\cdot t$ | J = W·s |
| 焦耳热 | $Q=I^2Rt$ | J |
| 电荷量 | $Q=I\cdot t$ | C = A·s |

### 常用换算

| 换算 | 关系 |
|---|---|
| 1 马力（hp） | $\approx 745.7$ W |
| 1 度电 | 1 kWh = $3.6\times10^6$ J |
| 1 eV（电子伏特） | $\approx 1.602\times10^{-19}$ J |
| 1 大气压（atm） | $\approx 101325$ Pa $\approx 14.7$ psi |
| 摄氏转华氏 | $^\circ\text{F}=^\circ\text{C}\times 9/5+32$ |
| 摄氏转开尔文 | K $=^\circ\text{C}+273.15$ |

## E.3 dB（分贝）速查

dB 是对数比值：电压/电流用 $20\log_{10}$，功率用 $10\log_{10}$。

### 倍数 ↔ dB 对照

| 增益倍数（电压/电流） | dB（$20\log_{10}$） | 功率比 | dB（$10\log_{10}$） |
|---|---|---|---|
| 1.00 | 0 dB | 1 | 0 dB |
| 1.26 | +2 dB | 1.58 | +2 dB |
| 1.414（$\sqrt{2}$） | +3 dB | 2 | +3 dB |
| 1.5 | +3.5 dB | — | — |
| 2.00 | +6 dB | 4 | +6 dB |
| 3.16 | +10 dB | 10 | +10 dB |
| 4.00 | +12 dB | 16 | +12 dB |
| 5.00 | +14 dB | 25 | +14 dB |
| 10.0 | +20 dB | 100 | +20 dB |
| 100 | +40 dB | $10^4$ | +40 dB |
| 1000 | +60 dB | $10^6$ | +60 dB |
| 0.707（$1/\sqrt{2}$） | −3 dB | 0.5 | −3 dB |
| 0.5 | −6 dB | 0.25 | −6 dB |
| 0.1 | −20 dB | 0.01 | −20 dB |

### 常用换算口诀

| dB 变化 | 效果 |
|---|---|
| +3 dB | 电压 ×1.414，功率 ×2 |
| +6 dB | 电压 ×2，功率 ×4 |
| +20 dB | 电压 ×10，功率 ×100 |
| −3 dB | 幅度下降到 0.707，即截止频率点 |
| −20 dB | 幅度降到 1/10 |

## E.6 温度换算与热敏电阻

| 转换 | 公式 |
|---|---|
| °C → K | K = °C + 273.15 |
| °C → °F | °F = °C × 9/5 + 32 |
| 常见温度点 | 水凝固 0°C / 人体 37°C / 水沸腾 100°C / 室温 25°C（298K） |

NTC 热敏电阻常用 B 值公式：

$$\frac{1}{T}=\frac{1}{T_0}+\frac{1}{B}\ln\frac{R_T}{R_0}$$

其中 $T_0=298.15\text{K}$（25°C），$R_0$ 为 25°C 阻值，$B$ 为材料常数（常见 3950）。
