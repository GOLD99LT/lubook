# 开关、接插件、连接器与保险丝 Switch / Connector / Fuse

这一章讲三类"连接/保护"器件：开关（Switch）控制通断，连接器（Connector/接插件）实现可拆卸连接，保险丝（Fuse）在过流时切断电路保护后级。它们不参与信号处理，但可靠性问题（抖动、接触不良、误熔断）却占现场故障的很大比例。

## 1. 设计动机

::: motivation 没有这些器件会怎样
要手动控制设备，就得有开关；要方便地插拔模块/线束，就得有连接器；要在短路时保护电源和后级，就得有保险丝。它们是人机交互和安全的最后一环——一颗氧化的连接器针脚，可能让整台设备时好时坏，极难排查。
:::

## 3. 关键参数

| 器件 | 参数 | 含义 | 典型数量级 |
|---|---|---|---|
| 开关 | 触点额定 | 能切换的电压/电流 | 轻触按键 50mA@12V；船型开关 2~10A@250V |
| 开关 | 机械寿命 | 可操作次数 | 轻按键 $10^4$~$10^5$；船型 $10^4$ |
| 开关 | 抖动时间 | 按下/松开时触点弹跳时长 | 5~20ms，需消抖 |
| 连接器 | 接触电阻 | 针脚接触压降对应电阻 | mΩ 级，越小越好 |
| 连接器 | 额定电流/电压 | 每针脚承载能力 | 排针每针 1~3A；USB 约 1.5~3A |
| 连接器 | 插拔寿命 | 可 mating 次数 | 排针数十~数百次；USB 上万次 |
| 保险丝 | 保持电流 In | 长期不熔断的电流 | 按负载额定选 |
| 保险丝 | 熔断电流 It | 规定时间内熔断的电流 | 通常 2×In（快断） |
| 保险丝 | I²t | 熔断允许的焦耳积分 | 选管/后级配合 |

## 4. 选型要点与工程权衡

- **开关要消抖**：机械触点按下/松开时会弹跳几~十几 ms，直接读 IO 会得到多次跳变。用 RC 硬件消抖或软件延时滤波。
- **连接器按电流降额**：每针额定电流要留裕量（实际 ≤50%~70%），多针同时载流时发热叠加。信号针与电源针分开排布，避免串扰。
- **连接器注意接触电阻与氧化**：关键信号/大电流位置选镀金触点（抗氧化、接触电阻低），别用镀锡；针脚数多的 FPC/排针注意插拔方向与锁扣。
- **保险丝选型**：快断（Fast-blow）用于精密半导体/过流敏感；慢断（Slow-blow/T）用于有浪涌的场景（电机、电容充电），避免上电浪涌误熔断。保持电流按最大正常工作电流选，熔断电流约 1.5~2 倍。
- **PPTC 自恢复保险丝**：可反复使用，但动作慢、漏流大、耐压有限，不能替代安规保险丝做最终保护。

## 5. 典型应用电路：按键输入与消抖

下图是最常见的轻触按键接法：IO 内部上拉，按键按下接地；并一个电容做硬件消抖：

![按键输入电路：上拉电阻、按键接地、RC 消抖](../assets/schematics/switches-connectors-fuses-debounce.svg)

::: example 按键消抖取值
1. **需求**：MCU GPIO 接轻触按键，按下读到低电平，要消除 10~20ms 抖动。
2. **硬件消抖**：用上拉电阻 $R=10k\Omega$（或 MCU 内部上拉），按键两端并电容 $C=0.1\muF$，时间常数 $\tau=R C=10k\times0.1\muF=1ms$——配合软件再延时 10~20ms 判读。
3. **软件消抖**：检测到电平变化后延时 10~20ms 再读，确认稳定才动作。
4. **保险丝**：电源入口按最大负载电流 1.2~1.5 倍选慢断保险丝，如整机 0.5A 选 1A 慢断。
:::

## 6. 失效模式与常见坑

::: pitfall 常见坑
- **开关抖动导致误触发**：现象——按一次键，MCU 收到多次按键事件。原因——机械触点弹跳。解决——RC 硬件消抖 + 软件延时判读。
- **连接器接触不良/氧化**：现象——设备时好时坏、晃动线束就断通。原因——针脚氧化、松动、插拔不到位。解决——关键位置用镀金触点、加锁扣，大电流针脚留裕量。
- **保险丝误熔断**：现象——一上电就烧保险。原因——选了快断管，但上电浪涌（大电容充电/电机启动）超过熔断点；或电流选太小。解决——有浪涌场景用慢断（T 型），按 1.5~2 倍正常电流选。
- **连接器针脚载流不足发热**：现象——多针连接器发烫。原因——每针电流接近额定，多针叠加发热。解决——按 ≤50%~70% 降额，大电流用多针并联或专用大电流连接器。
:::

## 7. 自测题

<details><summary>机械按键为什么要消抖？一般抖动时间多长？</summary>

机械触点按下/松开时会发生物理弹跳，产生几~20ms 的多次通断。不消抖，MCU 会把一次按压识别成多次。通常用 RC 硬件消抖 + 软件延时 10~20ms 二次确认。
</details>

<details><summary>电机/大电容上电场景，该选快断还是慢断保险丝？</summary>

选**慢断（T 型）**。这类场景上电有浪涌电流（电机启动、电容充电），快断保险丝会被浪涌误熔断；慢断管能承受短时浪涌，只有持续过流才熔断。
</details>

<details><summary>关键信号/大电流连接器为什么推荐镀金触点而不是镀锡？</summary>

镀锡触点易氧化，接触电阻随时间增大、时通时断；镀金触点抗氧化、接触电阻低且稳定，适合关键连接和频繁插拔。代价是成本更高。
</details>
