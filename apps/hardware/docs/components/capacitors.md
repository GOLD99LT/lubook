# 电容器全解：MLCC、电解、钽、薄膜 Capacitor

电容器（Capacitor）在两片导体极板间夹一层绝缘介质（Dielectric），靠电场储存电荷。它的伏安关系是 $i=C\,dV/dt$：**对直流相当于开路（充满后无电流），对交流相当于通路（电压变化就有电流）**。它是仅次于电阻的第二大用量元件，承担去耦、储能、滤波、耦合、定时等功能。但电容的"水很深"——同样标 10µF，MLCC 和电解的实际表现天差地别。

## 1. 设计动机：为什么电源旁边要并电容

::: motivation 没有去耦电容会怎样
芯片内部门电路瞬间翻转时，需要从电源轨抽取一个瞬态电流脉冲。如果电源到芯片的走线有电感，瞬态电流会在走线上产生压降，使芯片电源脚电压瞬间塌陷（dV = L·di/dt），导致逻辑错误、复位。在芯片电源脚就近并一颗电容，就像在水龙头旁放一个小水箱——瞬态需求由本地电容立刻供给，不必等远处电源。这就是去耦（Decoupling）。
:::

## 2. 电路符号与结构

基本符号是两条平行极板。无极性电容（陶瓷/薄膜）两板对称；电解/钽电容有极性，正极用"+"或空心极板标注。下图给出符号与常见封装外形：

![电容器电路符号与常见类型外形](../assets/schematics/capacitors.svg)

::: analogy 直觉类比：电容像"水箱/水库"
把电压比作水位，电荷比作水量。电容就是一个横截面积 $C$ 的水箱：往里面加水（充电荷 $Q$）水位才上升（电压 $V$），$Q=CV$。水位变化越快（dV/dt 大），进出水量越大（电流 $i=C\,dV/dt$）。直流稳态下水位不变，没有进出水（开路）；交流像水位不停涨落，水不断进出（导通）。
:::

## 3. 关键参数与类型对比

| 参数 | 英文 | 含义 | 典型数量级 |
|---|---|---|---|
| 标称容量 | Capacitance | 极板间储存电荷能力 | pF~µF~F（超级电容） |
| 额定电压 | Rated Voltage | 长期工作最大直流电压 | 6.3V~50V（常用），高压可达 kV |
| 容差 | Tolerance | 容量偏差 | J=±5%，K=±10%，M=±20% |
| 温度特性 | Temp Characteristic | 容量随温度变化 | C0G/NP0 ±30 ppm/℃；X7R ±15%；X5R ±15% |
| 等效串联电阻 | ESR | 电容内部串联的等效电阻 | MLCC 数 mΩ；铝电解数百 mΩ~Ω |
| 等效串联电感 | ESL | 引脚/极板寄生电感 | 数 nH，封装越小越低 |
| 纹波电流 | Ripple Current | 允许的交流电流有效值 | 电解电容关键参数 |
| 寿命 | Lifetime | 电解电容在额定温度下的寿命 | 105℃/2000h~10000h，每降 10℃ 寿命翻倍 |

按介质分，四类主流电容特性互补：

| 类型 | 优点 | 缺点 | 典型用途 |
|---|---|---|---|
| MLCC 陶瓷（Class I C0G/NP0） | 极稳定、低 ESR/ESL、低损耗 | 容量做不大（nF 级） | 高频滤波、谐振、定时、精密 |
| MLCC 陶瓷（Class II X7R/X5R） | 体积小容量大、便宜 | **直流偏置下容量暴跌**、压电噪声 | 电源去耦主力 |
| 铝电解 Aluminum | 容量大、便宜 | ESR 大、有寿命、高频差、有极性 |  bulk 储能、低频滤波 |
| 钽电容 Tantalum | 体积小、稳定、ESR 低于铝电解 | 过压浪涌易短路起火、贵 | 板级储能、空间受限 |
| 薄膜 Film（PET/PP） | 稳定、低损耗、耐压高、无感 | 体积大、贵 | 安规跨接、音频、高频 |

## 4. 选型要点与工程权衡

- **去耦组合**：每颗 IC 电源脚放一颗 0.1µF（100nF）MLCC 滤高频，近处再放一颗 1~10µF MLCC 或钽电容供中频瞬态，板级入口放大容量电解做 bulk。小电容滤高频是因为 ESL 小、谐振频率高。
- **MLCC 必须留电压裕量，且警惕直流偏置降额**：X7R/X5R 在施加直流电压后实际容量可能掉到标称值的 30%~60%。选 5V 电路去耦不要用 6.3V/10µF 的 X7R，应选耐压更高（如 16V）或 C0G，或并联多颗补足。这是 MLCC 最容易踩的坑。
- **C0G 用于需要稳定容量的地方**：谐振电路、RC 定时、积分器——这些地方容量漂移直接导致频率/时间误差。X7R 在这些场合会让振荡频率飘到不可接受。
- **电解电容看寿命与温度**：电源入口的电解电容是整板寿命短板。105℃/2000h 的型号在实际 60~70℃ 下寿命可延长数倍，但要选 105℃ 而非 85℃，并留纹波电流裕量。
- **钽电容怕浪涌**：上电浪涌或瞬态过压可能让钽电容短路起火。串联限流电阻或选降额更严（≤50% 额定电压）的型号，关键位置谨慎使用。

## 5. 典型应用电路：IC 电源去耦

下图是典型的电源到 IC 的去耦网络：bulk 电解 + 中频 MLCC + 高频 0.1µF，分别覆盖不同频段：

![IC 电源去耦电容组合：bulk 电解 + MLCC + 0.1µF](../assets/schematics/capacitors-decoupling.svg)

::: example 去耦电容取值理由
1. **0.1µF MLCC**：贴近 IC 电源脚，ESL 小（数 nH），自谐振频率在 10MHz 以上，专滤芯片瞬态高频噪声；引线越短越好。
2. **10µF MLCC/钽**：距芯片几厘米，供中等频段（几百 kHz~几 MHz）的电荷储备，补充 0.1µF 在中低频的不足。
3. **100µF 铝电解**：板级电源入口，做 bulk 储能，应对整板较大的电流突变；ESR 大、高频差，所以不能指望它滤高频。
4. 三者并联是因为单个电容阻抗在很窄频段才低，并联后宽频带阻抗都低。具体阻抗-频率曲线见 [电容参数：耐压、ESR、ESL 与失效模式](capacitor-parameters.md)。
:::

## 6. 失效模式与常见坑

::: pitfall 常见坑
- **X7R 直流偏置降额导致去耦不足**：现象——5V 电路用 6.3V/10µF X7R，实测容量只剩 3µF，电源纹波大。原因——Class II 陶瓷在直流偏置下介质极化饱和，容量大幅下降。解决——选耐压 2~3 倍于工作电压的 MLCC，或改用 C0G/钽，多颗并联补足有效容量。
- **铝电解干涸失效**：现象——设备用几年后电源纹波变大、输出掉压。原因——电解电解液随时间/温度蒸发，ESR 升高、容量下降。解决——选 105℃ 长寿命型号、留纹波与温度裕量，关键设备定期更换。
- **钽电容过压短路起火**：现象——上电瞬间钽电容冒烟甚至引燃。原因——浪涌或反压击穿氧化膜，钽电容失效呈低阻短路，持续过流发热。解决——降额到 ≤50% 额定电压、串限流电阻、避免浪涌，或改用 MLCC。
- **陶瓷电容压电效应致噪声/微音**：现象——音频电路里敲击/振动电路板，喇叭听到"咔哒"声。原因——X7R 陶瓷是压电材料，机械应力转成电信号。解决——音频敏感位置用 C0G 或薄膜电容，或让电容承受更少机械应力。
:::

## 7. 自测题

<details><summary>为什么去耦要同时放 0.1µF 和 10µF，而不是只放一颗 10µF？</summary>

因为 10µF 大容量电容通常 ESL/介质损耗大，高频下阻抗高、来不及响应芯片瞬态；0.1µF 小电容 ESL 小、高频特性好。并联后小电容管高频、大电容管中低频，宽频带电源阻抗都低。单颗 10µF 在 MHz 以上基本失效。
</details>

<details><summary>同样标 10µF/25V 的 X7R MLCC，用在 12V 电路里，实际有效容量会怎样？</summary>

X7R 在直流偏置下容量下降。25V 电容施加 12V（约 48% 额定电压）时，有效容量可能从 10µF 降到 5~7µF 左右（具体看材质与封装）。若工作电压更接近额定值（如 20V），掉得更厉害。这就是 MLCC 必须按实际偏压选容量的原因。
</details>

<details><summary>C0G/NP0 陶瓷电容为什么适合做 RC 定时和谐振电路，而不适合做大容量去耦？</summary>

C0G 容量极稳定（±30 ppm/℃）、损耗低，定时/谐振需要稳定的 RC 时间常数，所以选它；但 Class I 介质介电常数低，做不大容量（通常 nF 级），做大容量体积/成本不可接受，因此大容量去耦用 X7R/X5R。
</details>
