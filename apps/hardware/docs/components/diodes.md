# 二极管：整流、快恢复、肖特基 Diode

二极管（Diode）是最简单的半导体器件：一个 PN 结，只允许电流从阳极（Anode）流向阴极（Cathode），反方向基本不导通。它的符号是一个三角形顶一根竖线——箭头指向就是正向电流方向。它把交流电"整流"成直流，也做续流、隔离、保护。

## 1. 设计动机：为什么需要"单向阀门"

::: motivation 交流电直接接负载会怎样
市电是 50Hz 交流，电压正负半周来回翻转。如果直接接电子设备，负半周会让电源/芯片反向偏置而损坏。二极管就像水管里的**单向阀门**：只让一个方向的电流通过，把负半周"砍掉"，这就是整流。开关电源里，电感关断时要给电流一条泄放通路，也靠二极管（续流二极管）。
:::

## 2. 电路符号与工作原理

![二极管电路符号、伏安特性曲线与关键参数](../assets/schematics/diodes.svg)

::: analogy 直觉类比：二极管像"单向阀门 + 开启压力"
水流要顶开阀门，得先克服弹簧压力——这对应二极管的正向压降 $V_F$：硅管约 0.6~0.7V，必须超过这个电压才明显导通。反向时阀门关死（近似不漏水），但压力太大（超过反向耐压）会把管子撑破（反向击穿）。
:::

正向导通后电流急剧上升，但两端压降基本维持在 $V_F$。反向只有极小漏电流，直到反向电压超过 $V_{RRM}$ 发生击穿。

## 3. 关键参数与类型

| 参数 | 英文 | 含义 | 典型数量级 |
|---|---|---|---|
| 正向压降 | VF | 导通时阳极-阴极电压 | 硅整流 ≈0.7~1.1V；肖特基 ≈0.3~0.5V |
| 反向耐压 | VRRM (Peak Reverse Voltage) | 能承受的最高反向电压 | 50V、100V、400V、1000V |
| 平均正向电流 | IF(AV) | 长期允许的平均直流电流 | 1N4001≈1A；肖特基 SS34≈3A |
| 反向恢复时间 | trr | 从导通转到反向阻断所需时间 | 普通整流 µs 级；快恢复 50~100ns；肖特基 ≈0 |
| 反向漏电流 | IR | 反向截止时的微小电流 | 肖特基较大（mA 级，高温更甚） |

三类常用二极管：

| 类型 | 特点 | 用途 |
|---|---|---|
| 普通整流（1N400x） | VF 大、trr 慢（µs）、便宜 | 50/60Hz 市电整流 |
| 快恢复/超快恢复 | trr 几十~几百 ns | 开关电源、高频整流 |
| 肖特基（Schottky） | VF 低（0.3~0.5V）、trr≈0，但耐压低、漏电流大 | 低压大电流整流、续流、防反接 |

## 4. 选型要点与工程权衡

- **低压大电流优先肖特基**：$V_F$ 低意味着导通损耗 $P=V_F\cdot I$ 小。5V/10A 输出用 0.4V 肖特基比 0.9V 硅管少耗 5W，效率与发热差别巨大。
- **高压/高频别用肖特基**：肖特基耐压通常 ≤100V，且漏电流随温度升高急剧增大，高温下可能过热；高压场合用快恢复硅二极管。
- **反向恢复是开关电源的关键**：普通整流管 trr 慢，在高频开关时反向未及时关断，产生大反向电流尖峰、增加损耗和噪声。SMPS 续流/整流必须用快恢复或肖特基。
- **按峰值浪涌留裕量**：上电时大电容充电形成浪涌电流，二极管要能承受峰值浪涌电流（I_FSM），别只看平均电流。
- **串联压降要算进去**：防反接电路串一颗二极管，$V_F$ 会吃掉一部分电压（5V 系统吃 0.4~0.7V），低压系统要权衡，或改用 MOSFET 理想二极管。

## 5. 典型应用电路：半波整流与滤波

下图是最简单的半波整流：交流输入经二极管只取正半周，再由电容滤波成较平滑的直流：

![半波整流：交流经二极管取正半周，电容滤波输出直流](../assets/schematics/diodes-rectifier.svg)

::: example 整流滤波取值
1. **需求**：交流 9V  RMS 输入，整流滤波后给 5V LDO 前级。
2. **整流**：选 1N4001（50V/1A）半波或全桥，工作频率 50Hz 无需快恢复。
3. **滤波电容**：半波整流后电容取值 $C\approx I_{load}/(f\cdot \Delta V)$。负载 0.1A、允许纹波 1V，则 $C\approx0.1/(50\times1)=2000\mu F$，取 2200µF/25V 电解。
4. **注意**：电容充电只在交流峰值附近发生，二极管导通角小、峰值电流大，要确认二极管浪涌额定足够；全波/桥式整流纹波频率加倍（100Hz），所需电容更小。
:::

## 6. 失效模式与常见坑

::: pitfall 常见坑
- **肖特基高温漏电流过热**：现象——肖特基在高温下发烫、甚至烧毁。原因——肖特基反向漏电流随温度指数上升，漏流×反向电压变成额外损耗发热，形成正反馈。解决——高温环境选低漏流型号、降额、加散热，或改用硅快恢复。
- **高频误用普通整流管**：现象——开关电源二极管发热、效率低、有尖峰。原因——trr 太慢，反向恢复电流尖峰大。解决——换快恢复/肖特基。
- **防反接二极管压降吃掉电压**：现象——5V 系统经二极管后只剩 4.3V。原因——串联 $V_F$。解决——低压大电流改用 P-MOSFET 做理想二极管（压降 mV 级），或接受压降。
- **反向耐压不足击穿**：现象——二极管反向击穿短路、烧电源。原因——线路感性尖峰/浪涌超过 $V_{RRM}$。解决——按峰值电压留 ≥2 倍裕量，感性回路加 RC 吸收或 TVS。
:::

## 7. 自测题

<details><summary>硅二极管和肖特基二极管的正向压降大约各是多少？低压大电流选哪个？</summary>

硅管 $V_F\approx0.6\sim0.7V$（大电流时到 1V 以上），肖特基 $V_F\approx0.3\sim0.5V$。低压大电流选**肖特基**，因为 $P=V_F\cdot I$，低压降意味着小得多的导通损耗和发热。
</details>

<details><summary>为什么开关电源的续流二极管要用快恢复或肖特基，而不是 1N4001？</summary>

开关频率高（几十~几百 kHz），1N4001 反向恢复时间 µs 级，在每个开关周期都有较长时间反向导通，产生很大反向恢复电流尖峰，导致损耗和发热、EMI 恶化。快恢复/肖特基 trr 短，能及时关断。
</details>

<details><summary>防反接串二极管时，5V/2A 负载会损失多少功率？</summary>

用肖特基 $V_F\approx0.4V$：损耗 $P=0.4\times2=0.8W$，且输出被拉低到约 4.6V。若用硅管 0.7V 则 1.4W。这就是为什么大电流低压防反接常用 MOSFET 理想二极管。
</details>
