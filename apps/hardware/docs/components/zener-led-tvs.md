# 稳压管、LED 与 TVS/ESD 保护管 Zener / LED / TVS

这一章是"特殊二极管"群：稳压管（Zener Diode）工作在反向击穿区做电压基准；发光二极管（LED）正向导通时发光；瞬态抑制二极管（TVS）像一只高速大功率稳压管，专门吸收 ESD 和浪涌。它们都以 PN 结为基础，但工作在各自特殊区域。

## 1. 设计动机

::: motivation 三个小器件解决三类问题
- 想要一个稳定的 3.3V 基准给 ADC 用？普通二极管正向压降随电流温度变，不稳；稳压管在反向击穿区电压几乎恒定。
- 想做电源指示灯/照明？LED 正向导通发光，但必须串电阻限流，否则瞬间烧毁。
- 外部接口（USB、按键、天线）随时可能被人体 ESD（几千伏）打坏？在接口对地并一颗 TVS，瞬态高压到来时它瞬间导通钳位，把能量泄放掉。
:::

## 3. 工作原理与关键参数

| 器件 | 关键参数 | 含义 | 典型数量级 |
|---|---|---|---|
| 稳压管 | VZ (Zener Voltage) | 反向击穿稳压值 | 2.4V~几十 V，常用 3.3V/5.1V/12V |
| 稳压管 | PZ | 额定功耗 | 0.5W、1W、5W |
| LED | VF | 正向压降（随颜色） | 红 1.8~2V；绿/蓝/白 2.8~3.3V |
| LED | IF | 正向电流 | 指示 2~5mA；照明 20~数百 mA |
| TVS | VRWM | 反向工作电压（不动作） | 略高于被保护线路正常电压 |
| TVS | VC | 钳位电压（瞬态时两端电压） | 远低于后级器件耐压 |
| TVS | PPP (Peak Pulse Power) | 峰值脉冲功率 | 200W、600W、1500W |

::: analogy 直觉类比
- **稳压管**像"泄压阀的恒定开启压力"：反向电压一旦到 $V_Z$，它就击穿导通，把两端电压死死钳在 $V_Z$——前提是串个电阻限制电流，否则直接烧穿。
- **LED**像"通电就亮的小阀门"：但它没有自我限流能力，必须外部串电阻，否则电流失控。
- **TVS**像"快速动作的泄压阀"：平时不动（高阻），ESD 来纳秒级响应导通，把高压钳位在安全值，吸收大脉冲能量。
:::

## 4. 选型要点与工程权衡

- **稳压管必须配限流电阻**：$R=(V_{in}-V_Z)/(I_Z+I_{load})$。稳压管电流要落在数据手册推荐区间（如 5~20mA）——太小稳压不稳、噪声大；太大功耗发热。
- **稳压管是并联型稳压器**：效率低（小电流基准用），大负载建议用 LDO，稳压管只做简单钳位/基准。
- **LED 限流电阻**：$R=(V_{supply}-V_F)/I_F$。5V 驱红 LED（$V_F=2V$，$I_F=5mA$）：$R=(5-2)/0.005=600\Omega$，取 620Ω。
- **TVS 电压匹配**：$V_{RWM}$ 要略高于线路正常最高电压（如 3.3V 线路选 3.3V 或 5V TVS），保证正常不导通；$V_C$ 要低于后级芯片绝对最大额定值。
- **高速信号选低电容 TVS**：USB/HDMI/天线等高频线上，普通 TVS 结电容大（几百 pF）会把信号滤坏；要选专门的低电容（<1pF）TVS 阵列。
- **TVS 不替代过压保护**：它只扛瞬态脉冲，持续过压（如电源短路到 24V）会烧穿 TVS。

## 5. 典型应用电路

**稳压管并联稳压**：输入 $V_{in}$ 经限流电阻 R，稳压管反向击穿，输出被钳在 $V_Z$：

![稳压管并联稳压电路：Vin 经 R，Zener 反向击穿输出 VZ](../assets/schematics/zener-led-tvs-regulator.svg)

::: example 5.1V 稳压管基准取值
1. **需求**：$V_{in}=12V$，要给 ADC 一个 5.1V 基准，负载电流 5mA。
2. **选稳压管**：1N4733（5.1V/1W），推荐测试电流 $I_Z\approx49mA$。
3. **算限流电阻**：取稳压管电流 $I_Z=10mA$（兼顾负载），$R=(12-5.1)/(0.01+0.005)=460\Omega$，取 470Ω。
4. **算功耗**：R 上压降 6.9V、电流 15mA，功耗 ≈0.1W，取 0.25W；稳压管功耗 $P=5.1\times0.01=0.051W$（<1W，安全）。
5. **注意**：这是简单小电流基准，负载变化大时稳压值会飘，精密场合用基准源 IC。
:::

## 6. 失效模式与常见坑

::: pitfall 常见坑
- **稳压管无限流电阻而烧毁**：现象——稳压管冒烟/炸裂。原因——直接并联在高压上，击穿后电流失控。解决——必须串限流电阻，且电阻功率留裕量。
- **LED 不串电阻烧毁**：现象——LED 点亮瞬间就灭/发黑。原因——LED 正向近似恒压降，无电阻时限流全靠内部小电阻，电流过大。解决——按 $R=(V_{s}-V_F)/I_F$ 串电阻。
- **普通 TVS 拖慢高速信号**：现象——USB/以太网接 TVS 后通信失败。原因——TVS 结电容大，高频信号被衰减。解决——高速线选低电容 TVS 阵列。
- **TVS 被持续过压烧穿**：现象——接口短路到高压后 TVS 短路起火。原因——TVS 只设计扛瞬态脉冲，持续过压能量远超其脉冲容量。解决——前级加过压保护/保险丝，TVS 只做 ESD/浪涌。
:::

## 7. 自测题

<details><summary>稳压管为什么必须串联一个电阻？</summary>

稳压管工作在反向击穿区，击穿后伏安特性极陡——电压微小变化就引起电流剧变。不串电阻，电源内阻若很小，电流会无限增大导致功耗超标烧毁。串联电阻把电流限制在安全区间（几~几十 mA），并使稳压管工作在推荐电流点。
</details>

<details><summary>5V 电源驱绿色 LED（VF≈3V），要 5mA 电流，限流电阻取多大？</summary>

$R=(V_s-V_F)/I_F=(5-3)/0.005=400\Omega$，取 E 系列 390Ω 或 430Ω，实际电流约 4.7~5.1mA，功耗 ≈0.01W，0805/0603 足够。
</details>

<details><summary>TVS 的 VRWM 和 VC 分别应如何选？</summary>

$V_{RWM}$ 略高于被保护线路的正常最高电压，保证正常工作时 TVS 不导通、不影响电路；$V_C$（钳位电压）必须低于后级被保护器件的绝对最大额定电压，才能在 ESD 瞬态时把电压压到安全范围。
</details>
