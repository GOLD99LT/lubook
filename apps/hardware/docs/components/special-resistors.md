# 特殊电阻：热敏、压敏、光敏、电位器 Special Resistor

普通电阻的阻值只在工艺上固定，不随外界变化。这一章讲的特殊电阻则**故意让阻值随温度、电压、光照或机械位置变化**——它们把物理量"变成"电阻值，再由电路读出，本质是最简单的传感器或保护元件。

## 1. 设计动机：用"可变电阻"感知世界或保护电路

::: motivation 为什么不用专门的传感器
温度测量可以用昂贵的数字温度芯片，但在低成本场景，一颗 NTC 热敏电阻几分钱，配合一个分压电路就能测温；浪涌保护可以用复杂的 TVS+保险丝，但交流入口并一颗压敏电阻（MOV）就能吸收大部分雷击/开关浪涌。特殊电阻的价值在于：**被动、无源、便宜、可靠**，一个元件就完成"感知"或"保护"。
:::

## 3. 工作原理与关键参数

| 器件 | 英文/缩写 | 阻值随什么变 | 关键参数 | 典型数量级 |
|---|---|---|---|---|
| 负温度系数热敏电阻 | NTC Thermistor | 温度升高，阻值**下降** | R₂₅(25℃ 阻值)、B 值、耗散系数 δ | R₂₅=10kΩ 最常见；B≈3380；0℃≈100k，100℃≈0.7k |
| 正温度系数热敏电阻 | PTC / PPTC | 超过居里温度后阻值**陡增** | 保持电流 Ih、触发电流 It、耐压 | 自恢复保险丝，Ih 0.1~数 A |
| 压敏电阻 | MOV (Metal Oxide Varistor) | 电压超过阈值后阻值**骤降** | 压敏电压 Vₘ、最大浪涌电流、能量容量 | 275VAC 入口常用 ≈470V 压敏电压 |
| 光敏电阻 | LDR (Light Dependent Resistor) | 光照越强阻值**越低** | 亮阻/暗阻比 | 亮阻 ≈kΩ，暗阻 ≈MΩ（可达 100× 以上） |
| 电位器/微调 | Potentiometer / Trimmer | 机械轴转动改变阻值 | 总阻值、线性/对数指数、功率 | 10kΩ/50kΩ/100kΩ 常见 |

::: analogy 直觉类比
- **NTC** 像"怕热的水管"：越热，孔越大（电阻越小），水流越畅。
- **MOV** 像"泄压阀"：平时关着（高阻），压力（电压）一旦超过阈值就瞬间打开泄洪（低阻），把浪涌能量吃掉。
- **电位器** 像"可滑动的水龙头"：旋柄改变出水截面，从 0 到全开连续可调。
:::

::: advanced 进阶：NTC 的 Steinhart-Hart 与 Beta 近似
NTC 阻值-温度高度非线性，工程上常用 Beta 近似：
$$\frac{1}{T}=\frac{1}{T_0}+\frac{1}{B}\ln\frac{R}{R_0}$$
其中 $T_0=298.15K$（25℃），$R_0$ 为 25℃ 阻值，$B$ 为材料常数（如 3380K）。测温精度要求高时用三点 Steinhart-Hart 方程，并在 MCU 里查表或多项式线性化。
:::

## 4. 选型要点与工程权衡

- **NTC 测温**：选 R₂₅ 与测量电路匹配的（10kΩ 是行业标准，分压网络设计成熟）；注意自热误差——NTC 自身流过电流会发热，测温电流应小到自温升 <0.1℃。
- **NTC 浪涌限流**：电源入口冷启动时大容量电容充电会产生巨大浪涌电流，串一颗 NTC（常温高阻限流、发热后低阻）即可抑制；但要核算稳态功耗与恢复时间。
- **PPTC 自恢复保险丝**：替代传统保险丝做过流保护，过流发热后高阻切断，断电后自动恢复；但动作慢、有漏电流、耐压有限，不能替代安规保险丝。
- **MOV 浪涌保护**：按工作电压选（压敏电压要高于正常峰值并留裕量），按后级能承受的浪涌选通流容量；注意 MOV 老化（每次浪涌后参数漂移）与失效短路风险，前级应串保险丝。
- **电位器**：线性（Linear）用于分压/校准，对数（Audio/Log）用于音量（人耳对响度是对数感知）；频繁调节选导电塑料，只在出厂调一次选陶瓷微调（Trimmer）。

## 5. 典型应用电路

**NTC 测温分压**：NTC 与固定电阻分压，输出送 ADC。下图中 NTC 在上、R 在下，温度升高时 NTC 阻值下降，$V_{out}$ 随之变化：

![NTC 热敏电阻测温分压电路](../assets/schematics/special-resistors-ntc.svg)

::: example NTC 测温取值
需求：用 10kΩ B=3380 的 NTC，把 0~100℃ 映射到 ADC 的 0~3.3V。
1. 取分压固定电阻 $R=10k\Omega$（与 NTC@25℃ 相等，使 25℃ 时输出恰为中点 1.65V）。
2. $V_{out}=3.3\cdot R/(R+R_{NTC})$。25℃ 时 $R_{NTC}=10k$，$V_{out}=1.65V$。
3. 高温 100℃ 时 $R_{NTC}\approx0.72k\Omega$，$V_{out}\approx3.3\times10/10.72\approx3.08V$；低温 0℃ 时 $R_{NTC}\approx33.6k\Omega$，$V_{out}\approx3.3\times10/43.6\approx0.76V$。
4. R 取 10kΩ 而非 MΩ，是为了限制 NTC 自热电流、并匹配 ADC 源阻抗；R 上并 100nF 电容滤除引线噪声。
:::

## 6. 失效模式与常见坑

::: pitfall 常见坑
- **NTC 自热导致测温偏高**：现象——测出来的温度总比实际高 1~2℃。原因——分压电流过大，NTC 自身发热。解决——减小分压电流（增大电阻值但兼顾 ADC 源阻抗），或采用占空比极小的脉冲供电。
- **MOV 老化后失效短路起火**：现象——浪涌保护板用几年后烧保险、甚至冒烟。原因——MOV 每次吸收浪涌都会老化，最终击穿呈短路，持续工频电流引燃。解决——MOV 前级串联安规保险丝/热脱离，按 IEC 等级选足够通流容量，并定期检查。
- **电位器接触不良/噪声**：现象——调节时输出跳动、有杂音。原因——碳膜磨损、进灰、振动。解决——关键位置用密封型导电塑料电位器，或改用数字电位器；出厂一次校准的用微调并点胶固定。
- **LDR 响应慢、光谱敏感**：现象——亮灯后读数要几百毫秒才稳定，或对不同色温光源读数不一致。原因——CdS 光敏材料响应慢、对红光敏感。解决——快响应/精密场合改用光电二极管/光电三极管。
:::

## 7. 自测题

<details><summary>NTC 测温时，为什么要限制流过它的电流？</summary>

电流流过 NTC 会按 $P=I^2R$ 发热，使 NTC 自身温度高于被测环境，测温结果系统性偏高（自热误差）。需把功耗控制在自温升可忽略的范围（通常 <0.1℃ 对应的毫瓦级）。
</details>

<details><summary>MOV 在正常工作电压下近似导通还是近似开路？它失效时通常呈短路还是开路？</summary>

正常工作电压下 MOV 阻值极高，近似**开路**，不影响电路；当浪涌电压超过压敏电压时瞬间变低阻钳位。MOV 老化失效通常呈**短路**，因此前级必须串保险丝，防止短路后持续过流起火。
</details>

<details><summary>音量电位器为什么常用对数（Log）型而不是线性型？</summary>

人耳对响度的感知近似对数（声强每增 10 倍，响度才感觉翻倍）。对数型电位器让旋柄角度与主观响度近似线性对应，音量调节更自然；线性型会导致前半程音量几乎不变、后半程突然爆响。
</details>
