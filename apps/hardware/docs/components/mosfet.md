# MOSFET：参数、导通、驱动与损耗 MOSFET

MOSFET（金属-氧化物半导体场效应管）是**电压控制**器件：栅极（Gate）与沟道之间绝缘，直流下不取电流，只靠栅源电压 $V_{GS}$ 控制漏极电流。它开关速度快、导通电阻低，是现代开关电源、电机驱动、负载开关的绝对主力。分 N 沟道（NMOS）和 P 沟道（PMOS）。

## 1. 设计动机：为什么用 MOSFET 而不是 BJT

::: motivation BJT 要持续吃基极电流
BJT 是电流控制，基极要一直流几 mA 管子才导通，驱动电路有静态功耗；MOSFET 栅极绝缘，稳态几乎不取电流，只在开关瞬间给栅极电容充放电。于是 MOSFET 驱动简单、开关快、导通电阻低，做大电流（数 A~数百 A）开关时损耗远小于 BJT。
:::

## 2. 电路符号与工作原理

NMOS 符号：左侧栅极（一条竖线，与沟道绝缘），上端漏极 D、下端源极 S，源极带指向沟道的箭头。下图给出 NMOS 符号与电极：

![NMOS 场效应管电路符号与电极](../assets/schematics/mosfet.svg)

::: analogy 直觉类比：MOSFET 像"电压控制的电动阀门"
栅极就像阀门的控制按钮，但它是绝缘的——你只要给按钮加一个电压（$V_{GS}$），电场就把沟道"打开"，让漏极电流流通；松开电压（$V_{GS}<V_{th}$），沟道关闭。稳态按钮不耗电（绝缘），只在按下去/松开来回时给按钮电容充一下电。$V_{GS}$ 越大，沟道越宽、导通电阻 $R_{DS(on)}$ 越小。
:::

## 3. 关键参数

| 参数 | 英文 | 含义 | 典型数量级 |
|---|---|---|---|
| 栅极阈值电压 | VGS(th) | 刚开始形成沟道的 $V_{GS}$ | 逻辑电平 1~2V；标准 2~4V |
| 导通电阻 | RDS(on) | 完全导通时 D-S 间电阻 | mΩ~数十 mΩ（大电流管） |
| 漏极电流 | ID | 连续漏极电流 | 数 A~数百 A |
| 漏源耐压 | VDS | D-S 可承受电压 | 30V、60V、100V、600V |
| 栅极电荷 | Qg | 开关一次需转移的电荷 | nC 级 |
| 输入/输出电容 | Ciss/Coss | 栅极相关寄生电容 | pF~nF |
| 栅源最大额定 | VGS(max) | 栅极能承受的电压 | 通常 ±20V（绝缘层薄） |

## 4. 选型要点与工程权衡

- **按可用栅压选"逻辑电平"还是"标准"管**：MCU/栅驱只给 5V 甚至 3.3V，就必须选**逻辑电平 MOSFET**（在 $V_{GS}=4.5V$ 时 $R_{DS(on)}$ 已达标）；标准 MOSFET 需要 $V_{GS}=10V$ 才完全导通，用 5V 驱动会工作在高阻区、严重发热。
- **$R_{DS(on)}$ 随 $V_{GS}$ 变化**：数据手册的 $R_{DS(on)}$ 都标注测试 $V_{GS}$。务必按你实际能加的 $V_{GS}$ 查曲线，而不是直接取标称最小值。
- **$V_{DS}$ 留裕量**：按母线电压的 1.5~2 倍选。如 12V 母线选 30V 以上，48V 系统选 100V。
- **栅极驱动要够快**：栅极是电容，驱动不足会让开关过渡时间拉长、开关损耗暴增。栅极串小电阻（10~100Ω）抑制振铃，栅驱要能提供峰值电流给 Qg 充放电。
- **注意体二极管（Body Diode）**：MOSFET 内部 D-S 间有一个寄生反并联二极管，反向会导通。半桥/续流时要知道它的存在，必要时并联外部肖特基。
- **栅源电压绝对不能超 ±20V**：绝缘栅氧化层很薄，过压会永久击穿。栅极加稳压钳位/泄放电阻。

## 5. 典型应用电路与损耗

**NMOS 低边开关**：栅极经电阻接驱动信号，负载接在电源与漏极之间，源极接地。下图给出基本接法：

![NMOS 低边开关：栅极电阻、负载、体二极管](../assets/schematics/mosfet-switch.svg)

MOSFET 损耗主要三块：

$$P_{cond}=I_D^2 R_{DS(on)},\qquad P_{sw}\approx \frac{1}{2}V_{DS}I_D(t_{on}+t_{off})f_{sw},\qquad P_g=Q_g V_{GS} f_{sw}$$

::: example Buck 用 NMOS 取值
1. **需求**：12V→5V/3A Buck，fsw=400kHz。
2. **选管**：$V_{DS}$ 留裕量选 30V；$I_D$ 选 >5A；逻辑电平要求 $V_{GS}=4.5V$ 时 $R_{DS(on)}<20m\Omega$。
3. **算导通损耗**：$P_{cond}=3^2\times0.02=0.18W$，很小。
4. **算开关损耗**：过渡时间约 50ns，$P_{sw}\approx0.5\times12\times3\times(100e-9)\times400e3\approx0.72W$——开关频率高时这是主要损耗，需选低 $Q_g$ 管子并加强栅驱。
5. **散热**：总损耗 ~1W，选带散热焊盘的封装（SO-8/DFN）并铺铜。
:::

## 6. 失效模式与常见坑

::: pitfall 常见坑
- **栅压不足导致高阻发热**：现象——MOSFET 在开关时发烫、效率低。原因——用 3.3V/5V 驱动了需要 10V 的标准管，$V_{GS}$ 不足，$R_{DS(on)}$ 远超标称。解决——选逻辑电平 MOSFET，或加栅驱抬高 $V_{GS}$。
- **栅极悬空失控**：现象——MOSFET 半通半断、发热。原因——栅极高阻悬空，电荷积累导致 $V_{GS}$ 漂移。解决——栅源间并泄放电阻（10k~100k），保证关断时 $V_{GS}=0$。
- **栅极过压击穿**：现象——上电后栅极短路、管子失效。原因——驱动尖峰/米勒耦合超过 $V_{GS(max)}$(±20V)。解决——栅极加双向稳压钳位、串电阻。
- **dV/dt 误导通/穿通**：现象——半桥中一只管还没关，另一只刚开，瞬间直通短路。原因——漏极快速电压变化通过米勒电容给栅极注入电流致误导通。解决——加强栅极下拉、用栅极负压关断、加米勒钳位。
:::

## 7. 自测题

<details><summary>为什么 MOSFET 栅极稳态几乎不取电流？这对驱动有什么好处？</summary>

栅极与沟道之间是二氧化硅绝缘层，直流下没有导电通路，所以稳态 $I_G\approx0$。好处：驱动电路静态功耗几乎为零，不需要像 BJT 那样持续供基极电流，只在开关瞬间给栅极电容充放电。
</details>

<details><summary>MCU 3.3V GPIO 直接驱动一颗"标准 MOSFET"（需 10V 完全导通）会怎样？</summary>

$V_{GS}=3.3V$ 远小于完全导通所需的 10V，$R_{DS(on)}$ 远大于标称值，管子工作在高阻区，导通损耗巨大、严重发热甚至烧毁。应改用**逻辑电平 MOSFET**（$V_{GS}=4.5V$ 即 fully enhanced），或加专门栅极驱动器抬高栅压。
</details>

<details><summary>MOSFET 的导通损耗和开关损耗分别在什么频率下占主导？</summary>

低频时过渡次数少，开关损耗小，$P_{cond}=I_D^2 R_{DS(on)}$ 占主导；频率升高后 $P_{sw}$ 与 $P_g$ 随 $f_{sw}$ 线性增大，逐渐超过导通损耗，成为主要发热来源。所以高频场合要选低 $Q_g$、低 $C_{iss}$ 的管子并优化栅驱。
</details>
