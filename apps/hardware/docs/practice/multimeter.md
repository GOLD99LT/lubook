# 万用表使用与测量技巧 Digital Multimeter (DMM)

## 1. 为什么先学好万用表

::: motivation 万用表是硬件工程师的"听诊器"
示波器看得快但接起来麻烦，电源一上电，第一个要做的往往是：量一下各路电压对不对、有没有短路、电流多大。一块便宜的手持数字万用表（Digital Multimeter，DMM）就能完成电压、电流、电阻、通断、二极管、甚至温度/电容的测量。**它的价值不在于精度多高，而在于"随手可测、立刻定位"。**
:::

新手最容易犯的错不是不会用，而是**用错档位、接错孔**：测电压却插在电流孔，一搭到电源上直接短路烧保险丝。所以先把"电压并联、电流串联、电阻断电"这三句话刻进肌肉记忆。

## 2. 工作原理

万用表内部核心是一块**模数转换器（ADC）**，把被测电压数字化后显示。其它量都是"先变成电压，再读电压"：

- **电压档**：被测电压经精密分压电阻衰减到 ADC 量程内，直接读数。
- **电流档**：电流流过表内已知小阻值**分流器（shunt）**，测其上压降，按 $R=V/I$ 反推电流。
- **电阻档（Ω 档）**：表内输出一个已知小电流/小电压到被测电阻，测压降换算电阻。
- **通断档**：电阻低于阈值（典型 < 30~50Ω）就蜂鸣，用来找连线、查短路。

正因为电流档内部是一根**小电阻**，它必须串进回路；一旦并联到电压上，电流会经这个小电阻瞬间短路——这就是烧表的根源。

## 3. 关键指标

| 指标 | 典型手持表 | 含义与怎么看 |
|---|---|---|
| **直流电压基本精度** | ±(0.5%+1 字) 起，好表 ±(0.025%+...) | 误差 = 读数×% + 末位±字，见下式 |
| **输入阻抗** | 电压档典型 10 MΩ | 越大对被测电路影响越小 |
| **电流档分流电阻** | mA 档几 Ω，μA 档几百 Ω | 串联后压降 = I×Rshunt，会"吃"一点电压 |
| **最大读数/量程** | 3½ 位 1999、4½ 位 19999 | 位数越高分辨越小，但速度越慢 |
| **带宽（AC）** | 真有效值 1kHz 起步 | 普通表只对正弦波准，非正弦要用 True RMS |
| **CAT 等级** | CAT II / CAT III | 测市电/插座必须 CAT III 以上，关乎人身安全 |

精度误差的完整写法（以 3½ 位、量程 20V、读数 5.00V 为例）：

$$\Delta V = V_{read}\times a\% + b = 5.00\times 0.5\% + 0.01 = 0.025 + 0.01 = 0.035\text{ V}$$

即真实电压落在 $5.00\pm0.035\text{ V}$。多出来的"几个字"是 ADC 量化误差。

## 4. 接线与操作

主图是最常用的**测电压**接法：红表笔插 VΩ 孔，黑表笔插 COM 孔，档位选直流电压（V⎓）或交流（V~），**并联**在被测两点之间。

![万用表电压档：黑笔 COM、红笔 VΩ，并联在 Rload 两端读电压](../assets/schematics/multimeter.svg)

操作三步：
1. **先选对插孔**：VΩ/COM 测电压电阻；mA、10A 孔只在测电流时用，测完立刻插回 VΩ。
2. **先选大量程再往下减**：不知道大概多少时，量程调到最大，再逐步减小直到读数位数最多。
3. **手不要碰金属笔尖**：高压时既危险，人体电阻也会并联进高阻电路造成读数偏差。

## 5. 测量示例（含计算）

::: example 例 1：量 LDO 输出是否为 3.3V
- 黑笔接 GND，红笔接 LDO 输出脚，直流电压档。
- 读数 3.28V。手册标称 3.3V±2% → 允许范围 3.234~3.366V，3.28V **合格**。
:::

::: example 例 2：用分压估算高电压，扩大量程
要测一个 50V 而表只有 20V 量程：串一只 $R_1=100\text{M}\Omega$ 上分压，表内阻 $R_{in}=10\text{M}\Omega$ 作下分压。被测电压大部分落在 R1，表上只取 $R_{in}$ 这一份：
$$V_{meas}=V_{in}\times\frac{R_{in}}{R_1+R_{in}}=V_{in}\times\frac{10}{100+10}=\frac{V_{in}}{11}$$
被测 50V 时表上读数约 $50/11\approx4.55\text{V}$，乘倍率 11 即还原 50V。
- 功耗：$P=V^2/R_1=50^2/100\text{M}\Omega\approx25\mu\text{W}$，几乎不发热。
- 耐压：R1 上承受几乎全部 50V，须选 **100V 以上耐压**的高压电阻；100MΩ 属高阻，注意表笔/板面积污漏电影响读数。
:::

::: example 例 3：测电流时别忘了它会"吃"电压
串入 mA 档，分流电阻约 $R_{sh}=1\Omega$，回路电流 100mA，则表上压降 $I\times R_{sh}=0.1\text{V}$。若原电路供电只有 3.3V，这 0.1V 足以让低压电路行为变化——高电流测量优先用"测串联小电阻上压降再算"的办法，见扩展。
:::

## 6. 上手操作清单

- [ ] 上电前先用**通断档**查电源对地是否短路（蜂鸣=危险，别上电）。
- [ ] 第一次上电，**手不离开电源开关**，串电流表看总电流，异常立刻断电。
- [ ] 量每路电源电压，与设计值对照，超差先查电源再查负载。
- [ ] 测二极管：正向 0.6V 左右（硅），反向无穷大/OL，判方向与好坏。
- [ ] 长期监测电流用"串联采样电阻 + 测压降"，避免一直占着表、也避免分流压降影响电路。

## 扩展与变种电路

### 扩展1：电流串联测量法 Series Ammeter

要测回路真实电流，必须把回路**断开**，让电流全部从表内分流电阻流过。

![断开 Rload 处导线，DMM 电流档串入回路，红笔移到 mA/10A 孔](../assets/schematics/multimeter-current.svg)

::: example 接法与计算
- 红表笔从 VΩ 孔换到 mA（或 10A）孔，档位选直流 A。
- 断电 → 断开回路一根线 → 两表笔串入 → 通电读数。
- 例：测得 $I=0.15\text{A}$，Rload=20Ω，则负载压降 $I\times R=3\text{V}$，与电源吻合。
- 分流压降：mA 档 $R_{sh}\approx1\Omega$，0.15A 时表上吃掉 0.15V，低压供电要计入。
:::

对比"并联测电压"：电压档内阻 10MΩ 几乎不取电流；电流档内阻是小电阻，串进去必然分压。**高电流、低压供电场合优先用外置采样电阻法**（扩展 2 的思路），把表当电压表用。

::: pitfall 电流档并联到电源上 = 直接短路
- **现象**：插着 mA 孔去测排针间"有没有电压"，一搭就冒火花、表内保险丝烧断。
- **原因**：电流档内阻只有几 Ω，并联到电源相当于导线短路。
- **解决**：测电压前确认红笔在 VΩ 孔；养成"测完电流立刻插回 VΩ"的习惯。
:::

### 扩展2：断电测电阻与通断 Ohms & Continuity

Ω 档靠表内小激励测被测电阻，**必须断电**；通断档专查"这两点通不通"。

![Rx 脱离电源，DMM Ω 档两笔直接搭两端；通断档测连线是否导通](../assets/schematics/multimeter-ohm.svg)

::: example 操作与判读
- 电阻档：断电、至少一端脱离电路，否则并联支路会让读数偏小。读数直读；在线测只能作"下限参考"。
- 通断档：两点间电阻 < 约 30~50Ω 蜂鸣。用来顺着走线找网络、查"该连的连没连"。
- 例：蜂鸣档查 GND 平面，所有应该共地的点都应响；不响的点就是断开处。
:::

对比在线测 vs 拆一端测：在线读数含并联支路，**只能判短路/开路，不能用来核对标称值**；要准就拆一端。

::: pitfall 带电测电阻烧表 + 读数乱跳
- **现象**：电阻档一搭带电节点，读数跳来跳去甚至显示 OL/负值。
- **原因**：Ω 档把被测件当电源回路，外部电压叠加进去；高压还可能损表。
- **解决**：测电阻/通断前确认被测电路已断电、大电容已放完电。
:::

## 7. 常见坑与故障现象

::: pitfall 常见坑
- **档位与插孔不一致**：旋钮在电压档但表笔插在 mA 孔，去测电压时电流档低阻造成局部短路，读数异常或烧保险丝。**测什么量就插什么孔。**
- **忘了 10MΩ 输入阻抗带来的负载**：测高内阻节点（如 MOS 栅极、高阻分压中点）时，10MΩ 表并上去直接改变分压比，读数比真实值偏低。高阻测量要用高输入阻抗表或先算负载效应。
- **普通档测非正弦波有效值**：测 PWM、整流后波形用"平均值校准"档会差很多，必须切到 True RMS（真有效值）档。
- **量程没选对**：显示 1.988V 却还停在 20V 档，只有 3 位有效数字；降到 2V 档能多一位精度。
:::

## 8. 自测题

<details><summary>要测一块 5V 电源给负载供了多大电流，表笔应该插哪个孔、怎么接？</summary>
红笔插到 mA（或 10A）孔、黑笔 COM；断电后**断开负载回路一根线**，把 DMM 串进去再通电。电流档内阻小，不能像测电压那样直接并在电源两端——那等于短路。
</details>

<details><summary>用 10MΩ 输入阻抗的万用表测一个由两个 1MΩ 电阻组成的分压中点，读数会比真实值偏高还是偏低？</summary>
偏低。表 10MΩ 与下分压 1MΩ 并联后等效约 0.91MΩ，分压比被拉低。高阻节点测量前要把表的输入阻抗算进分压。
</details>

<details><summary>通断档一接 GND 平面就响，但顺着走线某两点却不响，说明什么？</summary>
该网络存在断路/虚焊。通断档响说明导通电阻低于阈值；不响说明两点之间没有低阻通路，是开路点，重点查过孔、连接器、焊点。
</details>
